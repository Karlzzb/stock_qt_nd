# 🚀 快速开始 - 可视化持仓编辑器

## 1️⃣ 启动服务（30秒）

```bash
# 进入web_interface目录
cd web_interface

# 启动服务
python app.py
```

看到以下信息表示启动成功：
```
* Running on http://0.0.0.0:5000
```

## 2️⃣ 打开界面（10秒）

在浏览器中访问：
```
http://localhost:5000
```

或在手机上访问（确保在同一WiFi）：
```
http://你的电脑IP:5000
```

## 3️⃣ 编辑持仓（1分钟）

### 方式一：添加新持仓

```
1. 点击 "💰 资金持仓" 标签页
2. 点击 "编辑" 按钮
3. 点击 "➕ 添加新持仓" 卡片
4. 填写表单：
   
   股票代码 *     持仓数量 *
   [688528.SH  ]  [4500    ]
   
   平均成本 *     买入日期 *
   [11.71      ]  [2026-03-03]
   
   止损价格 *     止盈价格 *
   [10.30      ]  [15.22   ]

5. 点击 "💾 保存所有持仓"
```

### 方式二：修改现有持仓

```
1. 点击 "编辑" 按钮
2. 找到要修改的持仓卡片
3. 直接修改输入框中的数值
4. 点击 "💾 保存所有持仓"
```

### 方式三：删除持仓

```
1. 点击 "编辑" 按钮
2. 找到要删除的持仓卡片
3. 点击右上角 "🗑️ 删除" 按钮
4. 确认删除
5. 点击 "💾 保存所有持仓"
```

## 4️⃣ 常见问题（1分钟）

### Q1: 股票代码怎么填？

**正确格式**:
```
✅ 688528.SH  (科创板)
✅ 600561.SH  (上海主板)
✅ 000001.SZ  (深圳主板)
✅ 300750.SZ  (创业板)
```

**错误格式**:
```
❌ 688528     (缺少.SH或.SZ)
❌ SH688528   (顺序错误)
❌ 688528.sh  (小写)
```

### Q2: 哪些字段必须填？

标记 `*` 的字段都是必填的：
- 股票代码 *
- 持仓数量 *
- 平均成本 *
- 买入日期 *
- 止损价格 *
- 止盈价格 *

### Q3: 止损止盈怎么设置？

**建议**:
- 止损价格 = 成本价 × 88% (亏损12%)
- 止盈价格 = 成本价 × 130% (盈利30%)

**示例**:
```
成本价: 11.71
止损价: 11.71 × 0.88 = 10.30
止盈价: 11.71 × 1.30 = 15.22
```

### Q4: 保存失败怎么办？

检查以下几点：
1. 所有必填字段都填写了吗？
2. 股票代码格式正确吗？
3. 价格和数量是正数吗？
4. 网络连接正常吗？

## 6️⃣ 移动端使用（1分钟）

### 在手机上使用

1. **连接WiFi**
   - 确保手机和电脑在同一WiFi

2. **查找电脑IP**
   ```bash
   # Windows
   ipconfig
   
   # 找到 IPv4 地址，例如: 192.168.1.100
   ```

3. **手机访问**
   ```
   在手机浏览器输入:
   http://192.168.1.100:5000
   ```

4. **添加到主屏幕**
   - iOS: 点击分享 → 添加到主屏幕
   - Android: 菜单 → 添加到主屏幕
