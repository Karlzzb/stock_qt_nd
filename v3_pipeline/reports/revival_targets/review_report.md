## 1. 逐项必查结果

### 1.1 trunc1 目标定义审计（必查项 1）——通过，机制声称属实

`trunc1_hit__withATRN` 的标签构造与二代 lambdarank-hit **完全相同**（hit_N20_k2.0 二元标签、按事件日分组、C4 全 60 原始特征），唯一差异是 `lambdarank_truncation_level=1`（二代及三代默认 30）。
LightGBM 官方文档确认该参数控制 lambdarank 梯度计算聚焦的顶部位置数（默认 30），外层循环以 truncation_level 为界，即截断位之后的文档不参与配对梯度（[参数文档](https://lightgbm.readthedocs.io/en/latest/Parameters.html)、[实现解析](https://ffineis.github.io/blog/2021/05/01/lambdarank-lightgbm.html)）；历史上曾有截断被忽略的 bug（[issue #3420](https://github.com/microsoft/LightGBM/issues/3420)），但本环境 lightgbm 4.7.0 下 trunc=1/3/30 产出不同模型（逐日序列互不相同），截断实证生效。
因此"逐日只有 top1 配对有梯度"的机制描述属实：trunc=1 时每 query 仅当前最高分文档与其余文档的配对产生 lambda。
主池日截面 ≤30 事件恒成立（val 最大 230 事件/日但 trunc=30 与截断无关——验证：292 信号日中 >10 事件 55 天、最大 230，trunc=30 对 >30 事件的日才有别；主池仅个别极端日超过 30，"trunc=30≈无截断"成立——备池同理）。

**"头部聚焦 4/4 判平"与"截断排序过线"是否协议差异造假**：两个候选在同一协议（同一三段混用、同一网格、同一评估函数）下运行，唯一处理变量即截断水平本身，不存在候选间的协议不对称。
真正的归因问题（截断效应是信号还是选择伪影）由 §1.5 的置换零假设回答。
**设计缺口（如实记录）**：本批次未跑 (hit, trunc=30, 清洗宇宙) 锚点单元，"trunc1>trunc3>默认30"的剂量链默认端借用 v2 未清洗宇宙数值（C4 raw +1.35pp / C4 rank +2.08pp，同样是三段混用产物），跨宇宙可比性有限；建议终审批次补此单元。

### 1.2 复跑对拍（必查项 2）——通过

备份原产物后完整复跑 `run_revival_targets.py`（实测 123s，与声称 122~124s 一致）。
字段级拍平比对：`results_revival.json` 944 字段、`daily_curves.json` 15904 字段，**零差异、无增减键**。
`deterministic=True + seed=42` 可复现声称成立。

### 1.3 bootstrap 实现（必查项 3）——通过，种子稳健

实现核对：抽样单位=日（聚类单位正确，与日内截面相关结构匹配）；与 Wilcoxon 同一配对集（剔零差日，主 131/备 421，逐位复核一致）；双侧 p=2·min(尾概率)，(1+k)/(1+B) 防零；B=20000。
独立重算（自建基线日序列，不经执行方代码）：trunc1 主池五个种子（42/123/2024/777/31337）p ∈ [0.0003, 0.0008]，最劣种子 Bonferroni(8)=0.0064 仍过线；超额 +2.982pp、Wilcoxon 0.002437 逐位一致。
**发现 wart（方向保守）**：23 个 ≤3 事件日的 diff 为 −9.9e-09~−2.0e-08 的浮点噪声（pandas groupby 均值与 numpy 均值求和序差异），超过 1e-12 阈值混入非零配对集；这 23 个伪负号使 Wilcoxon 从 0.0005 抬高到 0.0024、bootstrap 均值从 8.06pp 稀释到 6.65pp——**执行方上报值偏保守**，不推翻任何结论，建议后续批次把阈值提到 1e-6 或统一求和路径。

### 1.4 几何通道排查（必查项 4）——主池排除成立；备池同号腿证明力弱

确定性重训三个截断配置（逐日序列与归档 0 天不符，模型级复现）后做选股层审计：

| 检验 | main/trunc1 | main/trunc3_withATRN | main/trunc3_noATRN | backup/trunc1 |
|---|---|---|---|---|
| top3 与 ATRN 升序 top3 逐日重合度（随机期望） | 0.374（0.326） | 0.412（0.326） | 0.377（0.326） | 0.472（0.379） |
| 日 spearman(score, −ATRN) | +0.097 | +0.325 | +0.213 | +0.311 |
| 选中事件 ATRN 日截面分位（池均值 0.5） | **0.495** | 0.429 | 0.495 | 0.475 |

零模型纯 ATRN 升序策略在清洗宇宙的机械底：**主池 +1.954pp（boot_p=0.012）、备池 +1.328pp（boot_p=0.033）**。

结论分池：
- **主池：几何通道被直接排除。** trunc1 选中事件的 ATRN 分位恰为池均值（0.495），分数与 −ATRN 仅弱相关（0.097）；任何"选低实现波动率股票"的变相几何（经 VSTD20/GK_VOL_RATIO 等代理）都必然在选中集 ATRN 分位上显形，而它是中性的。主池 +2.98pp 超出机械底 +1.95pp 且选股不倾斜——执行方声称 3 成立，且本复核的选股层证据比其"ATRN 不在增益前 8"的论据更强（增益排名不能排除分裂使用，选中分位可以）。
- **备池：trunc1 有明显几何倾斜（corr 0.311、重合度高于随机 25%），且 +0.95pp 低于纯 ATRN 机械底 +1.33pp。** 备池"同号"一腿不能视为独立增量证据——它同时被几何通道与三段混用零假设（§1.5）覆盖。预登记门只要求同号，形式上满足，但终审不应把备池 +0.95pp 当作效应的独立佐证。

### 1.5 三段混用通胀量化（必查项 5）——通胀存在但不足以制造该阳性

设计：主池清洗宇宙，20 次日内×段内 (hit, mfe20) 联合置换（保当日边际分布、断特征→未来通道），每次跑完整协议（6 网格早停+选参+最终重训+验证段评估）全部 8 配置——零假设分布**包含全部选择机器**（早停自由度、网格选择、val top3 tiebreak、8 配置家族最大值）。

结果（/tmp/review_revival/permutation_null.csv）：
- 单配置零假设超额均值 +0.25~+0.90pp（trunc1 自身 +0.54pp，std 0.80）——**三段混用对单配置的期望抬升约 +0.5~0.9pp**。
- 家族最大值（8 配置取 max）：均值 +1.77pp、95 分位 ≈ +2.31pp、20 次最大 +2.64pp。
- **0/20 次家族最大值达到 +2.98pp**（经验 p ≲ 1/21）；trunc1 在零假设下仅 3/20 次成为 argmax（无结构性偏袒，头部标签配置同等频率夺冠）。

解读：三段混用+家族选择能凭空制造的量级上限约 +2.3~2.6pp（20 抽样式），实测 +2.98pp 在其上；扣除选择溢价的朴素预期残差 ≈ +2.1~2.4pp。
**对测试段终审的预期衰减**：选择溢价在测试段消失（无选参），天真预期 ≈ +2.4pp 量级；叠加 2022-11 后未见市场的 regime 衰减风险，即便再打对折仍 >+1pp——衰减空间存在但不致命，这正是值得终审而非直接否决的原因。
（局限：20 次重复对家族最大值尾部的估计较粗；零假设只含选择机器，不含"真实弱信号被放大"的交互项——该交互方向仍是抬高验证段数值，故测试段衰减概率不可消除，只能靠终审本身回答。）

### 1.6 逐年全正验证（必查项 6）——通过

自建基线逐年序列（与归档逐位一致）独立重算：

### 1.7 测试段纪律（必查项 7）——通过

特征矩阵虽延伸至 2026（predict 对全量行打分），但训练/早停/选参/评估/基线均经 train/val 掩码，测试段行不产生任何聚合量。

### 1.8 三个"不试"判定的机制论证（必查项 8）——成立

- **①触障时间**：非命中事件全部删失于同一标签值→相互之间 gain 相同、无梯度，新增学习压力只在命中类内部；而已实锤的失败模式是"非命中事件被排进 top3"，命中类内排序对该通道零贡献。机制推导在 lambdarank 梯度结构下成立，与已判平目标的重叠度声称属实。
- **③胜率×幅度混合**：hit×mfe20 在命中类=mfe20、非命中=0，是两个已判平目标的逐点插值；验收口径（top3 命中率）对幅度免疫，插值头顶不高于两端点头顶。成立。
- **④horizon 轴**：h10/h20 双侧夹逼判平，h5/h30 无信息存在的先验，且附保留条款（②或⑤出脉搏后可复诊）。成立。
- 小疵：报告 §1 称二代"top3 超额为零"，实际 v2 C4 raw 主池 +1.35pp（统计上与零不可分、未过任何线）——措辞偏紧但不影响论证。

## 2. 统计口径附注

- 多重比较：Bonferroni 与 BH-FDR 实现正确（trunc1 主池 Bonf(8)=0.0024、BH q=0.0024、16 家族 Bonf=0.0048，逐位复核）。
- Wilcoxon 交叉口径 Bonf(8)=0.0195<0.05，与 bootstrap 口径结论一致。
- bootstrap 估计量（非零差日条件均值 6.65pp）与上报口径（全 292 日日加权 +2.98pp）的估计对象不同：零差日=≤3 信号日的结构性零（96.3% 为零差日），剔零差与三代同口径且方向保守，可接受；但终审报告应把两个口径并列写清。
- head 标签正例率（0.367/0.189）与预登记预期（37%/19%）一致；候选②四配置 RankIC(hit) 双池齐跌（主 +0.03~0.05、备 ≤0）的判平证据链完整。

## 3. 保留意见汇总（均不推翻主结论）

1. **备池同号腿弱**：几何倾斜 + 低于备池 ATRN 机械底 + 落入混用零假设范围——终审判据应立主池，备池仅作同号形式检查（与预登记一致，但报告读者不应高估其权重）。
2. **缺清洗宇宙 trunc30 锚点**：剂量链默认端跨宇宙借用，终审批次应补 (hit, trunc30, 清洗宇宙) 与预登记已承诺的 trunc1_noATRN 对照。
3. **浮点噪声日 wart**：23 个 ≤3 事件日以 ~1e-8 负差混入非零配对集，使 wilx 偏保守 5 倍、bootstrap 均值偏保守 1.4pp；建议阈值提至 1e-6。

## 5. 裁决理由（通过而非部分推翻）

阳性的三个独立支柱均经独立重建存活：统计显著性（异种子 bootstrap + Wilcoxon 双口径 + Bonferroni/BH 双校正）、机制可区分性（选股层几何中性）、伪影上限（置换零假设含全部选择机器仍够不到 +2.98pp）。
执行方对联合作废风险（三段混用）的披露完整、自我定级（仅提审资格）与翻案局既定处置一致，无夸大表述。
遗留的三项保留意见均属终审设计层面，不影响"是否提审"的判定。
