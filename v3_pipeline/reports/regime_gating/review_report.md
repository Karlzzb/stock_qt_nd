### 4. 统计效力 —— 判定成立，但报告 §7 两处措辞越界

按配对构造推导的功效公式 MDE = (z_{1-α}+z_{0.8})·√E[r²]·√(1/n_k−1/n)（α=0.00125 单侧，功效 80%），独立数值验证（√E[r²] 主池 0.686/0.617，备池 0.635/0.647）：

| 代表规则 | MDE |
|---|---|
| 主池 train nk=37（c_rsNeg_belowMA250） | 41.5pp |
| 主池 train nk=68（c_aboveMA20_ddShallow） | 29.2pp |
| 主池 train nk=268（s_above_ma20，主池最优情形） | 9.1pp |
| 主池 val nk=59 | 27.7pp |
| 备池 train nk=269（c_aboveMA20_ddShallow） | 13.9pp |
| 备池 train nk=889（s_above_ma20） | 6.2pp |
| 备池 train nk=1182（s_below_ma250，全族最优情形） | 4.6pp |
| 备池 val nk=141 / nk=365 | 18.8pp / 9.1pp |

含义：
- 主池重跳过族（nk 24~74）在观测效应（5~10pp）处功效仅约 2%，"主池无活口"对这些族近乎统计空判；主池即便最优情形（nk=268）MDE 也有 9.1pp。
- 备池大样本规则（nk 889~1182）MDE 4.6~6.2pp，对 ≥6pp 的真实效应有足够检出力；备池重跳过族（nk~270）MDE ~14pp，不足。
- 因此"40 条规则双池均无活口"在预登记活口口径（train 显著 + val 保留 ≥50%）下是准确陈述，且 val 全面反号是正向证伪证据（并非单纯不显著），"无可复现提升"的判定成立、issue 评论无需勘误。

越界处（需勘误）：
- §7 末句"该信号池的命中变异不随常见指数体制状态单调变化"是实质性零效应断言，超出功效可支撑范围：主池对 <29pp 效应基本无检出力，备池不能排除 <5pp 效应。
  应改为"在预登记口径下未测到可复现提升（主池功效极低、备池仅对 ≥6pp 效应有充足功效，更小效应不可排除）"。
- §7"唯一双段同向的是主池浅回撤族"事实错误：备池有 11 条规则 train/val 双段双正（如 c_rsPos_aboveMA20 +3.57/+3.71 保留率 1.04、c_rsPos_volLow +1.16/+4.09、s_dd_deep +0.75/+1.60 等），只是幅度小且 train 均不显著。
  应改为"双段同向且幅度可观的只有主池浅回撤族"。

附带勘误：§6/§7"主池事件 2014 年起"括注错误。
主池 feature matrix train 事件 2001 年起每年都有（2001:9、2005:33、2011:76、2013:185、2014:309、2015:653、2016:1095、2017:238），仅 2013 年前稀疏；应改为"主池事件集中于 2013 年后"。
