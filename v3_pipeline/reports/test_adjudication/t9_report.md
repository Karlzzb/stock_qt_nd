## 工程正确性缺陷修复登记（预登记例外条款）

首次运行（15:03 前）类 C 逐笔重放断言 1/224 不一致：`688271.SH 2023-06-16→2023-06-20 rank_out 未复现`。

根因（实锤，非猜测）：**停牌僵尸仓**。
600781.SH 于 2023-06-19 开盘入场，当日即为其最后行情日（此后无 bar，永不平仓、不进 trades 表）。
引擎在 2023-06-19 评估时该仓在 positions 中，其当日面板分 0.52837 进入候选集，把 688271.SH（0.52712）挤出前三触发 rank_out —— 引擎行为与 T8 预登记口径（"当前持仓股"含当日新入场仓）一致，**引擎无缺陷**。
缺陷在重放断言脚本：在持集合仅从 trades 表重建，看不见永不平仓的僵尸仓，且遗漏"决策日收盘到期卖出仓当日仍在仓"的边界。

修复（均已逐位回归证明不改变任何交易行为）：

1. strategy_engine_v3 附加诊断输出 open_positions（窗口末在仓持仓）与 stats.open_at_end；trades/equity/stats 逐位不变。
2. 重放断言在持集合 = trades ∪ open_positions，并纳入决策日收盘到期仓。
3. 回归证据：17 条引擎单测（含 v1 E1 逐位对拍）全过；修改后引擎重跑 T8 归档 val_C15，trades(534)/equity(928)/stats 与归档产物逐位一致（验证段僵尸仓为 0，T8 结论不受影响）；修复后断言复验 val_C15 534/534 零不一致。
4. 修复后重跑 T9：三配置市场结果与首跑逐位一致（确定性引擎），类 C 重放 224/224 零不一致。

本次重跑属预登记"工程正确性缺陷修复后重跑"例外，首跑与重跑日志均保留于 t9_progress.log。
两轴评审后追加第三次运行（--allow-rerun 已登记理由）：修复一次性护栏口径——首跑 SystemExit 发生在裁决 JSON 落盘前导致护栏对失败型首跑无记录，现改为 attempt 史自阶段日志自举并写入 adjudication.json.one_shot_guard（attempt=3，prior_run_starts=2）；市场结果为确定性重算，与前两跑逐位一致。
