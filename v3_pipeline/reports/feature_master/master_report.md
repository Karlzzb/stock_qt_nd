## 验收断言

1. **三来源全部合并**：PASS。行数 == 特征矩阵行数；三来源列均在表（构建脚本硬断言）。
2. **泄漏排除**：PASS。排除模式 = V4/V5 训练配置 exclude_patterns ∪ feature_engine 14 条黑名单；命中 4 列（rank_return_rankpct / rank_volume_rankpct / rank_return_z / rank_volume_z，均为白名单两列的横截面衍生，日内单调变换、对排名模型无增量信息，剔除合理）；^rank_ 前缀规则对 rank_return / rank_volume（V2 全市场当日横截面百分位，T 日收盘可得的因果特征）白名单豁免，豁免项已登记。
3. **去重规则**：PASS。|ρ|≥0.999 判定用两池 train+val 段合并的精确成对完全观测相关系数（pairwise-complete，不涉标签），保留优先级 s1>s2>s3、同级按列名字典序；去重后断言保留列两两 |ρ|<0.999 通过。剔 380 列（s1 剔 5、s2 剔 212、s3 剔 163）。
4. **快照一致性**：PASS（抽样断言，非全量对拍）。两层证据：(a) 来源 3 重建时全市场抽样 12 股 × 3 事件日 = 30 个单元格，全历史快照值与"仅用不晚于当日数据前缀重算"值逐位一致（rtol 1e-9），0 不一致；(b) 主表构建末端新鲜抽检两池各 5 个事件（覆盖下限已加硬断言），0 不一致。抽样未覆盖的列族由单元测试已知值守护（横截面排名互补性、日历特征、大盘特征）与构造性因果论证（全为 rolling/shift/ewm/talib 回看算子）。合成数据单元测试另覆盖前缀稳定性。

去重口径预登记：|ρ| 判定只用两池 train+val 段特征值（不涉标签，不触 test 段信息做选择决策），保留集施于全表（含 test 段行——去重是列级机械操作，非逐行拟合）。

## 来源 3 重建的语义偏离登记（相对已删除的 feature_cache_v4_clean.parquet）

旧缓存与其上游 CSV 已在仓库瘦身时删除，来源 3 是从 stock_data/daily 原始日线的完整重建，以下偏离均已登记：

1. **窗口语义**：原管线把个股截尾 100 个交易日后算 talib 递推指标（MACD/RSI/ATR 等），指标值依赖窗口起点（种子效应），是"训练窗口 vs 实盘增量"的口径漂移源。重建改为个股全历史纯因果计算，事件日取值与前缀重算逐位一致（断言 4 保证）。
2. **不计算标签族**：future_return_* / stop_loss_return_* / *_sell_date_*（28 列）不作特征出现；标签由 #26 标签赛独立产出。
3. **不计算 V1 检测器事件列**（prev_time/formation_period/divergence_strength 等约 18 列）：它们是旧信号的几何属性，在 v5 池事件上无定义。
4. **pv_corr_10 跨股污染修复**：原实现未按 symbol 分组；逐股计算下污染天然消失。
5. **大盘族真实化**：复核代码确认旧缓存的大盘族为 _get_default_combined_features 的默认常数（hs_/gq_/hc_ 前缀恒值，旧管线指数数据未加载成功）；新快照用真实指数计算（sh_/sz_ 前缀，20 列 + 横截面变体）。
6. **横截面 cs_* 排名群体为当日全市场**，与原 enrich 语义一致（原 target_df 为全市场当日行，非仅信号股）；逐日群体内部排名，无前视。
7. **rank_return / rank_volume** 为全市场当日横截面百分位（原口径），单独全市场 pass 计算。
8. 次新股（总历史 <100 行）不计算，特征 NaN（备池 9 事件）。

独立复核（证伪式，全部自算、不信任构建脚本自报）七项全部 PASS：

2. 词典中文名缺口（457 个 s3 保留列 cn_name 为空）——已修复：按 V2 族名前缀映射 + 变体后缀规则补齐，保留列中文名覆盖率 100%。
3. 备池 9 个次新股事件无 s3 快照（<100 行守卫），s3 列记 NaN，已登记。
4. RET_ON（s1，复权感知 pre_close 口径）与 ret_overnight（s3，close.shift 口径）在除权日口径不同（ρ=0.99926），去重保留前者（口径更优），属已登记的源差异。

另：白名单豁免的 rank_return / rank_volume 实际被去重删除（锚为 s2 工厂同式列），最终主表中该两列不存在，豁免规则成为纯防御条款。
