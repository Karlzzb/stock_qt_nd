# 项目总档：MACD 背离事件驱动狙击模型 —— 全部方向关闭（2026-09-02）

本文档是背离狙击项目的最终档案。
三层方向（池内排序、池级策略、池级敞口择时）全部经预登记协议+真实交易回测+独立复核证伪。
权威档案为 GitHub issues（#1 决策索引），本文档汇总证据链与幸存资产。

## 一、项目命题

以 MACD 背离为唯一事件底座，构建 A 股事件驱动狙击模型。
底座信号池经 #6 重设计后确立：主池（分形15+三件套+上涨段，验证期狙击命中 64.7%、超零信息基线 +15pp、盈亏比 2.21）与备池（zigzag05 无过滤）。
底座本身从未被证伪，且不受后续任何战役结论触及。

## 二、三层证伪证据链

### 第一层：池内排序（#10-#17，2026-08~09）

问题：能否用特征+模型在池内挑出更可能命中的事件。
结论：不能，七方向+测试段终审全灭。

- #10 参数网格：冠军守擂。
- #11 信号组合：四池零增益。
- #12 事件级门控：40 规则无活口。
- #13 几何收益：命中率被盈亏比对消。
- #14 P2 补数据特征：0/15。
- #16 特征工厂：1603 列终选被随机特征集反超（特征无真信息的决定性证据）。
- #15/#17 唯一活口 trunc1：验证段 +2.98pp（p=0.0003），测试段终审衰减至 +0.66pp（p=0.55）否决——确认段收益在真·样本外消失的标准案例。

### 第二层：池级策略（#18，2026-09-02）

问题：不排序，池信号直接接资金曲线（真实交易模拟：资金约束、T+1、涨跌停、印花税/佣金/滑点），还剩多少。
结论：池级零信息组合≈中证500；主动管理全负。

- 76 配置真实交易回测，前 3 名测试段 0/3 过验收线（年化>中证500 且回撤≤15%）。
- 败因是回撤（-31%~-41%），不是收益（最好配置超指数 +14.9pp）。
- 消融实锤：边际全部来自"20 日满仓持有"，缩短持有期即被成本吞没（成本/毛利比 0.71~0.93）。
- val 赢家在 2015-2018 稳健性段全灭（回撤 -65%~-77%），跨段不稳健。

### 第三层：池级敞口择时（#19，2026-09-02）

问题：用大盘状态控制整体仓位，能否压下 #18 的败因（回撤）。
结论：买到了一部分回撤，但不够，且收益代价更大。

- 16 配置（2 底座×4 择时×2 闸门），前 3 名测试段 0/3 过线。
- 择时买到 6.7~12.5pp 回撤（仍差线 5.8~10.2pp），代价年化 2.4~23.4pp。
- val 段"免费午餐"（趋势60+硬闸门：回撤降且年化增）在测试段不成立。

## 三、总账

| 层 | 方向 | 结论 | 关键证据 |
|---|---|---|---|
| 排序层 | 特征+模型挑事件 | 证伪 | 测试段终审 +0.66pp/p=0.55 |
| 策略层 | 池信号+主动管理 | 证伪 | 0/3 过线；主动管理净毁价值 |
| 择时层 | 大盘状态控仓位 | 证伪 | 回撤买不够、收益先赔光 |
| 底座 | 背离信号池 | 未证伪 | 验证期 64.7%/+15pp/PF2.21 |

统一的残余解释：池收益边际与"20 日满仓持有、不择时、不择股"的被动暴露强绑定。
该边际在真实交易约束下约等于指数（中证500），任何形式的主动管理都只是在该暴露上做减法。

## 五、教训（写给未来的自己）

1. 验证段既早停又评估的上报值必然虚高，"逐年全正+p 值极小"也不足以代替真·样本外终审。
2. IC/命中率类的统计边缘不等于可变现边缘；经济意义必须在真实交易约束下检验。
3. 成本是边际的第一杀手：持仓越短、换手越高，成本吞没得越干净。
4. "回撤≤15%"对纯多头 A 股在 2022-2026 历史段可能本来不可及（同期中证500 自身 -31%）；验收线本身需要与策略形态匹配。
