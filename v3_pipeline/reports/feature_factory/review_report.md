## 4. 保留意见（不撼动裁决）

1. **摘要措辞挑最大值**：3 个随机种子全跑全报（报告 §3），但执行方摘要只引各变体最大者（+1.90/+1.99）。
   主池 rank 变体 3 个随机集仅 1 个严格反超终选（+1.84 > +1.16，另 1 个持平）。
  "随机反超"的正确表述是"终选集落在同尺寸随机集分布之内，无可检测筛查增益"。
2. **p 值精度**：B=5000 下 boot p=0.0000 的诚实上界是 p<2×10⁻⁴，摘要"p<0.0001"略越界（方向为加重己方否定证据，保守方向）。
3. **ATRN-only 控制本身不稳**：单特征模型 rank/raw 变体理论上同排序，实测主池 +1.04pp（iter=2）vs −0.67pp（iter=80），差异纯由叶粒度决定的并列打破方式产生——裸 ATRN 控制本身含 ±0.7pp 量级的并列噪声。
  "增量 0.1~0.4pp"仅在 rank 变体成立；raw 变体相对 ATRN-only-raw 的增量为主池 +2.74pp / 备池 +0.33pp（跨池不一致，本就不过线）。
4. **漏斗数值细节未落盘预登记**：主表 6.3 的"稳定性三关"被 issue #16 一句话的交互感知路线取代，50%/25%/30/top60/3 种子等参数仅存在于脚本 docstring。
  否定性结果 + 全量披露 + 随机对照使此事后果有限，但后续战役应把漏斗参数写进 issue 再动手。
