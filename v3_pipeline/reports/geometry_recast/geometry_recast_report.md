# 验收口径重铸：ATRN 升序几何基线规则的收益类裁决（issue #13）

> 实验对象：topn_density 复核实锤的无模型规则"密集日（>10 候选）ATRN 升序 top3"（命中率 +6.61pp、p=0.0215，但命中率口径为循环论证）。
> 本实验按预登记改用收益类口径裁决其是否构成可用交易规则。
> 脚本：`v3_pipeline/scripts/run_geometry_recast.py`（可复跑，实测 24s）。
> 数值：`results_geometry_recast.json`；进度流水：`progress.log`（阶段+心跳）。
> 实验日期：2026-09-02。测试段（2022-11 起）封存未碰。

## 1. 预登记设计（与任务书逐条对应）

**规则组**（全部无模型、T 日收盘前可算）：
- R1：密集日（候选数 >10）ATRN 升序 top3（原几何规则）。
- R2：密集日 ATRN 降序 top3（反向对照）。
- R3：密集日随机 top3，重复 200 次取分布（蒙特卡洛对照，seed=42+rep）。
- R4：全池基线（所有信号日全候选等权）。

**收益口径**（T+1 开盘买入，与 hit_N20_k2.0 标签同一几何）：
- 主变体 TP：20 交易日内 high 触及 入场价+2×ATR14[T] 即按**触及价**于触及日止盈，否则第 20 日收盘卖出。
- 稳健变体 TPSL：另加 low 触及 入场价−2×ATR14[T] 按触及价止损；同日双边同触**保守记止损**（悲观假设）。
- 触发判定用原始价（与标签机器一致），收益用 pct_chg 累积因子 cf 做除权除息调整（口径假设已注明：触及价成交、日内先后不可知时取悲观）。
- 费用：佣金双边各 0.1%、印花税卖出 0.05%（往返净拖累 −0.24985%）；**滑点假设 = 0**（精确按 开盘/触及价/收盘 成交）。

**指标**：每笔期望净收益、PF（总盈利/总亏损）、盈亏比、胜率，及按日等权组合净值（持仓逐日盯市、无持仓日记 0、段界后未平仓部分不计）的最大回撤与夏普。
**切分**：train 2001-2018 / val 2019-01~2022-10，隔离带 2018-11-19~2018-12-28 与 2022-09-13~2022-10-31 丢弃（同 race_rerun_v2）。
**池清洗**：excluded_events_{main,backup}.parquet 中 f_any==True 剔除，应用于全部规则（主池剔 372、备池剔 2138）。
**判定**：R1 须在双段同时满足 PF>1 且不劣于 R4（期望净收益与 PF 均不劣）才可用；R1 在 R3 分布中的分位给出随机性排除证据；若 R1 双段都不如 R4 或 R3 中位数，判"不可用"并关闭。

## 2. 数据锚定（先于一切结论）

- **hit 标签锚定 100%**：自写模拟链的"20 日内触及 +2×ATR"布尔与 labels.parquet 的 hit_N20_k2.0 在 train+val 全部有效事件上逐位一致——主池 n=5701、备池 n=25544，一致率均 = 1.000000。
  复核机器与标签机器同构，收益口径与命中率口径的几何完全相同，唯一差别是结算用钱。
- **ATRN 口径锚定**：规则排序直接用特征矩阵的 ATRN 列（与 #8 实验同一列）；抽查 fm ATRN vs talib.ATR14/close（原始价）——主池 max|diff|=3.1e-06；备池 000001.SZ 12 事件 max|diff|=7.4e-03（特征引擎的 ATRN 用复权价、标签几何用原始价，除息日附近有小差；排序用 fm 原列、触发用原始价 ATR，各随其原始口径，互不影响结论）。
- **宇宙**：特征矩阵键集合（主池清洗后 7782 事件 / 3953 股；备池 34848 事件 / 5509 股），dense 日数：主池 train 46 / val 55；备池 train 335 / val 172。
- **marks 自洽校验**：每笔交易逐日盯市 marks 复利复利乘积与净收益精确相等（|diff|<1e-12，抽样 138 条全过）。
- 过程中抓获并修复一处收益核算 bug（除权因子误乘在退出价上而非基准价上，致毛收益虚高约 2 倍），修复后重跑，本报告全部数字出自修复后链路。

## 4. 判定（按预登记逐条核对）

1. **PF>1**：R1 在全部 8 个格子（2 池 × 2 段 × 2 变体）PF 均 >1（1.061~1.933）——此条单独通过。
2. **不劣于 R4**：主池 train E[net] +1.61% vs R4 +3.97%、PF 1.882 vs 2.809，双指标均显著劣；主池 val E[net] +0.94% vs +1.04% 亦劣（仅 PF 1.500 vs 1.304 占优）；备池两段 E[net] 与 PF 全面劣于 R4。——**不通过**。
3. **随机性排除**：R1 的 E[net] 在 R3 分布中的分位——主池 train 6.5%、主池 val 50.5%、备池 train 0.0%、备池 val 0.0%。
   四个格子中三个处于 6.5 分位以下，**没有任何一个格子展现优于随机的证据，备池两段显著差于随机**。
4. **预登记关闭条款**："若 R1 双段都不如 R4 或 R3 中位数，判不可用"——备池 R1 双段 E[net] 低于全部 200 次随机抽取（即低于 R3 中位数且低于 q05）；主池 train 亦双指标劣于 R4 与 R3 中位。条款触发。

**裁决：不可用。** ATRN 升序几何规则在收益口径下不构成可用交易规则，issue #13 的"活口问题"答案为否，应关闭。

## 5. 机制解读（与前序复核互洽）

- 命中率优势被赔率劣势精确抵消：主池 val R1 胜率 0.703（高于 R4 的 0.656，与 +6.61pp 命中率实锤一致），但盈亏比仅 0.63（R4 0.68、R2 0.81）——低 ATR 股票"更容易碰到 +2×ATR"恰恰因为它们的 2×ATR 更窄，命中时赚得少、未命中时 20 日期满的漂移亏损照付。
- 期望收益 = 胜率 × 平均盈 − 败率 × 平均亏，几何规则只优化了第一项里的胜率，且优化幅度被第二项吞掉：主池 val R1 与随机 top3 的期望净收益差（+0.94% vs 中位 +0.93%）为零。
- 备池方向干脆反转：R2（高 ATRN）两段两变体全面优于 R1，且 R1 低于全部随机抽取——"低 ATR 更安全"在经济上为假，它是标签几何的截面表达，不是风险调整后的收益来源。
- 组合层面另一个诚实的提醒：R4 全池基线自身在 train 段组合 Sharpe 仅 −0.22（TP），MDD −82%（2008 年），即"信号池本身有正单笔期望、但满仓等权持有的组合路径并不能兑现"——池内排序问题与池子本身的可交易性是两个问题，本实验只裁决前者。

## 6. 口径与局限（自列）

- 止盈按触及价成交、滑点为 0 是乐观假设；同日双触记止损是悲观假设；两者方向相反，未做净敏感度分解。
- 密集日样本量小：主池 train 46 日 / val 55 日（138/165 笔），单笔层面的抽样噪声大——但备池（335+172 日、1005+516 笔）给出同向且更强的否定证据，结论不依赖主池小样本。
- 段界截断：val 段末未平仓头寸的段界后盈亏不计入组合曲线（单笔指标不受影响）。
- 等权口径：R4 为全候选等权，未做仓位/资金管理；不同加权不改变 R1 vs R3/R4 的相对结论方向。
- 测试段（2022-11 起）全程未触碰；exit 窗口最迟消费 2022-10 月中行情（与标签机器相同）。
