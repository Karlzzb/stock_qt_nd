## 0. 数据与纪律

- 数据源：`daily_basic/`（换手率/流通股本，8715 日全量）、`stk_limit/`（2007-01-04 起，北交所无覆盖）、`index/`（4 宽基）、`meta/namechange.parquet`（ST 历史）、`meta/sw_index_classify+member`（申万 2021 版一级行业，含 in/out 历史）。
- **禁用**：`ths_index/ths_member`（仅当前快照=前瞻性）与 `stock_basic_industry`（当前快照，无历史）——未用于任何历史特征。
- 切分：train 2001-01-01~2018-12-31 / val 2019-01-01~2022-10-31（含两段隔离带剔除）；2022-11 后测试段封存，只落特征值不入统计。
- 池清洗：统计样本 = 事件 ∩ `f_any==False`（f_st|f_suspend|f_limitup，来自 pool_cleaning）。ST_FLAG 例外：f_st 会抽干其截面变差，其主读数用 `f_suspend|f_limitup` 口径（保留 ST 事件）。
- 主池 m_fractal15_full（标签 w_fractal_o15_s20）、备池 m_zigzag05_nofilter（标签 w_zigzag_p05_s5），标签 hit_N20_k2.0。
- 全部特征只用于信号日 T 收盘后可得数据；行业归属按 T 时点 in_date≤T<out_date as-of 重建；申万只覆盖其评级股票（面板行业覆盖率见 run_meta），未覆盖股特征为 NaN。

### 泄漏防线：截断历史重算对拍（主表 7.2-1）

- **样本A_个股级截断**：3 股 × 50 日, 比对 947 值, 容差超出倍数峰值 0.00e+00 -> 通过
- **样本B_面板级截断**：12 个截断日 × 当日全部事件, 比对 3692 值, 容差超出倍数峰值 0.00e+00 -> 通过

## 6. 数据缺陷与口径备注

- `stk_limit` 2007 年以前无数据：精确涨跌停族在 2007-01-04 前为 NaN（有效年度 2007 起 16 年），北交所（.BJ）全期无覆盖为 NaN。
- 申万一级行业 as-of 重建：重叠区间（168 只股票存在重叠）取 in_date 最新者，过期不回退；未评级股票为 NaN。
- `daily_basic` 早年（1991-1995）少量缺行按 NaN 处理；2016-06-30 等个别日期小批量缺行（接口缺报）同。
- ST_FLAG 的 as-of 规则与 pool_cleaning f_st 完全同口径（已通过 ±5% 涨跌幅交叉验证）。
- IND_MOM20 与 IND_RS_RANK 的逐日 Rank IC 完全相同（日内截面单调变换），建模时二选一；IND_REL_STR = 个股 RET20 − 行业 RET20，与 RET20 族存在构造性相关。
- LIMITCNT20_X 年度一致率 1.00 仅覆盖 4 个有效年（2016/2020/2021/2022；2015 年 8 个 IC 日未达 10 日下限且为正），主池早期日截面过薄时分辨力有限（复核报告 §3-4 同源风险）。
- DIST_LIMIT_X 对长期停牌复牌首日（无涨跌幅限制但接口挂公式值）会产出大比值，已截断至 ±1.5。
