## 一、裁决口径（用户拍板，冻结）

1. **窗口**：事件日 ∈ 2011-09-01 ~ 2026-08-31，逐字沿用 #32 §一.1（含截断条款与已披露代价）。
2. **判活线 = 口径 D（纯现金字面版）**：同时满足以下三条——
   - 单位在投超额 = excess_cash ÷ capital_utilization > +10pp；
   - 资金利用率 capital_utilization ≥ 0.5；
   - sharpe_cash > 0.5（纯现金口径权益曲线，日收益均值/标准差×√252，口径同 #32 §五）。
   - excess_cash = 纯现金口径净年化超额 = 策略年化 − 基准年化，基准 = 上证指数，口径逐字沿用 #32。
3. **宣判规则**：每格独立对判活线、全出数；多格过线时按单位在投超额取首；无终审段（沿用 #32 披露 3）。
4. **多重比较披露**：格子总数 = 9,450（§三），全部出数全部对线。

## 二、动机与机制说明（出数前披露）

- 跨实验结构事实（#38 复核坐实）：口径 D 三条件中，**在投质量与夏普均已有格单独过线，唯一绑死的是资金利用率 0.5**——
  - #32 旧网格 8 格单位在投超额（纯现金）>10pp 且 sharpe_cash>0.5，全部卡在利用率 0.359~0.371；8 格全部位于 v6-3 池 / H25 / P2 / 出场 E1_A6 或 E1_A9，挑选规则 S1~S5 全覆盖（最优 +11.31pp = S4 随机，说明稀疏池上挑选规则间差异不大）。
  - #38 加厚把利用率网格均值顶过 0.5（K=5/3），但全接无精选的在投质量最高仅 +9.53pp。
- 本实验的机制回答：在 #32 的精选框架（仓位数上限 + 爆发日挑选规则）内把仓位数从 10 压到 K ∈ {3, 5, 7}——单仓变厚抬利用率，上限与挑选保留精选质量。
- **张力预警（诚实预期管理）**：精选与加厚对利用率方向相反——加厚抬单仓金额，精选与收紧上限减少入场笔数；#38 已证在投质量对纯加厚近似尺度不变，本实验的判活希望寄于"精选保留的在投质量 >10pp 在加厚后仍然保持"。若两条件仍无一格同时满足，则"利用率 0.5 对该信号族定义级不可达（与在投质量>10pp 联立）"的证据链闭合。

## 三、网格与 P7 规则（冻结）

1. **P7 精选加厚仓位规则（本实验唯一新增机制）**：
   - 仓位数上限 = K，**K ∈ {3, 5, 7} 为网格维**；单仓名义金额 = 100 万 ÷ K（K=10 即退回 P1 等仓十仓）。
   - 同日信号数超过空槽时按挑选规则排序接入（S1 先到先得 / S2 前 20 日跌幅最深 / S3 种子强度 / S4 随机 / S5 已弹最少+量比最冷），挑选语义逐字沿用 #32 §三。
   - 入场二次仓位检查、现金约束（单仓 ≤ min(名义金额, 可用现金)）、整手舍入、现金不足 1 手丢弃记 dropped_cash 不递补、槽满丢弃记 dropped_slot_full——全部逐字沿用 #32 入场块执行语义。
   - 即：P7 = #32 P1 框架把仓位数 10 换成 K，其余一概不动；不引入 P5/P6 的"全接+摊薄"语义。
2. **网格**：池(6: v6-1~v6-5 + ALL) × H(3: 10/20/25) × 出场(35，清单逐字沿用 #32 §3.1) × 挑选(5: S1~S5) × K(3: 3/5/7) = **9,450 格**。pos 段取值 P7K3 / P7K5 / P7K7。
3. **不变部分**：信号池、入场口径、成本常量、出场族执行语义、双口径记账、统计指标口径全部逐字继承 #32 §二/§三/§五，不重扫、不调参。
4. **对照**：P1/P2 同 (池, H, 出场, 挑选) 配置取自 #32 冻结产物 summary_portfolio.csv；P5/P6 同配置取自 #37/#38 冻结产物；均不重跑。

## 七、披露（预写，出数后原样保留）

1. 种子源自 2026 沙盒探索性扫描（沿用 #31 披露 1）。
2. 窗口砍掉 2008 产粮年，样本内大股灾 regime 只剩 2015（沿用 #32 §一.1）。
3. 无终审段：全窗口一次出数，如实披露（沿用 #32 §七.3）。
4. K=3 时单仓名义 33.3 万 = 总资金三分之一，组合集中度为历次实验最高；口径 D 的 sharpe_cash 条件即对此的风险约束，不另设集中度上限。
5. 口径 D 为拍板的判活线，旧终审线（+15pp 且 Sharpe>0.5，判活口径记账）只作参考列出数；本实验不回溯改判 #32/#37/#38 已归档结论。
6. 精选与加厚对资金利用率作用方向相反（§二张力预警）；若 0 格过线且头部格仍卡在"利用率与在投质量此消彼长"，则该张力即为本信号族在口径 D 下的结构性结论而非实现缺陷。
7. 8 个"在投质量过线"格中 S4（随机挑选）占 2 席且为最优（+11.31pp），说明稀疏池上精选增益主要来自"少接"而非"会挑"；本实验保留全部五种挑选规则，不据此事后偏爱 S4。
