## 一、裁决口径（用户拍板，冻结）

1. **窗口**：事件日 ∈ 2011-09-01 ~ 2026-08-31，逐字沿用 #32 §一.1（含截断条款与已披露代价）。
2. **判活线 = 口径 D（纯现金字面版）**：同时满足以下三条——
   - 单位在投超额 = excess_cash ÷ capital_utilization > +10pp；
   - 资金利用率 capital_utilization ≥ 0.5；
   - sharpe_cash > 0.5（纯现金口径权益曲线，日收益均值/标准差×√252，口径同 #32 §五）。
   - excess_cash = 纯现金口径净年化超额 = 策略年化 − 基准年化，基准 = 上证指数，口径逐字沿用 #32。
3. **宣判规则**：每格独立对判活线、全出数；多格过线时按单位在投超额取首；无终审段（沿用 #32 披露 3）。
4. **多重比较披露**：格子总数 = 630（§三），全部出数全部对线。

## 二、口径更正（拍板后监工复算发现，出数前披露）

- #35 档案（addendum_strategy_review.md §口径 D）字面写"纯现金口径 + 单位在投超额>10pp + 利用率≥0.5 + Sharpe(纯现金)>0.5 → 39 格过线"。
- 监工用 #32 冻结产物 summary_portfolio.csv 逐字复算：**纯现金字面版 0 格过线**；"39 格"实际是用判活口径（空仓买指数）超额 excess_idx 算单位在投超额得出的——空仓指数层污染混回，正是口径 D 要剔除的成分。
- 纯现金字面版下旧 12,240 格中 u≥0.5 者 3,363 格，单位在投超额最优 8.12pp（v6-1__H25__S2__P2__E2_B8），离 10pp 线差 1.9pp。
- 本实验终审线按字面口径 D（纯现金）执行；混合口径变体（excess_idx÷u > 10pp 且 u≥0.5 且 sharpe_cash > 0.5，旧网格 39 格）作参考列并列披露，不参与判活。
- #35 档案的更正（档案内修订注记 + issue 更正评论）由监工另行落盘，与本实验跑数无关。

## 三、网格与 P5 规则（冻结）

1. **P5 弹性仓位规则（本实验唯一新增机制）**：
   - 信号日收盘决策：当日池内信号**全部接入**，无仓位数上限；挑选规则（S1~S5）对 P5 无操作对象，网格不含 sel 维，内部遍历固定用 ts_code 升序（确定性）。
   - 单仓名义金额 = 100 万 ÷ max(10, 当日池内信号数 S)。S ≤ 10 时与 P1 一致（每仓 10 万）；S > 10 时全部接入、单仓摊薄。
   - 现金再摊薄：单仓金额 = min(名义金额, 信号日收盘后可用现金 ÷ S)。信号日收盘至入场日开盘之间无现金变动（#32 执行语义：入场先于当日卖出，卖出现金当日不可用），故该口径因果干净且与遍历顺序无关。
   - 入场执行时现金不足 1 整手 → 丢弃记 dropped_cash，不递补（沿用 #32）。
   - 入场日开盘的二次仓位检查对 P5 恒放开（上限 = 无穷），dropped_slot_full 恒 0。
2. **网格**：池(6: v6-1~v6-5 + ALL) × H(3: 10/20/25) × 出场(35，清单逐字沿用 #32 §3.1) × P5 = **630 格**。
3. **不变部分**：信号池、入场口径、成本常量、出场族执行语义、双口径记账、统计指标口径全部逐字继承 #32 §二/§三/§五，不重扫、不调参。
4. **对照**：P1/P2 同 (池, H, 出场) 配置的数字直接取自 #32 冻结产物 summary_portfolio.csv，不重跑。
