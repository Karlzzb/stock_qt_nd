# 阶段底信号当天识别赛 —— 预登记(先于任何跑数落盘)

实验日期:2026-09-04。
本 README 是预登记文件,先于任何跑数落盘。
候选名单、特征定义、阈值来源、判活线全部冻结于此,出数后不许增删改(唯一例外:R5 的 θ 按下方规定在训练段拟合后回填数值,并标注"仅训练段")。

## 0. 显著披露(三条,先于一切设计)

1. **R3 是代理,不是真利空数据**。
   用户假说"排除重大利空"需要新闻/公告数据,真实新闻数据因 token 过期不可得。
   R3 只用价格行为代理(跌停收盘 / 大幅跳空低开),它度量的是"价格已经崩了",不是"有利空消息"。
   此局限冻结于此,出数后不得美化表述。
2. **特征序列口径偏离任务书字面,属必要偏离**。
   任务书写"个股序列 = load_market_data 返回的该股 DataFrame",但该序列只带引擎自带 60 自然日前向缓冲(起点约 2025-11-03),到 2026-04-01 也仅约 100 个交易日,无法满足"事件日前 ≥120 个交易日历史"与 f1/f3/R1 的 120 根窗口。
   实测:若严守字面条文,2449 个(v1)基准宇宙事件中 1778 个(73%)历史不足,训练段近全军覆没,实验退化为空。
   因此冻结决策:**宇宙成员资格与交易模拟用引擎序列(对齐已复核口径与参照数 2449);特征 f1~f4 与规则 R1/R2/R3 用 stock_data/daily 全历史日线(同一批 parquet 文件、同一不复权口径,仅不被引擎的 60 日缓冲截断),在事件日处截断**。
   事件表 anchor_close 列不进任何特征;f4 分母用全历史序列在 anchor_date 的 close。
   "事件日前 ≥120 个交易日历史"的要求在全历史序列上执行,不足者剔除并逐笔披露(实测 v1 仅 6 个、v2 仅 4 个,均为次新上市,符合任务书"预期很少")。
3. **near/far 分组标签是事后信息**。
   标签只用于训练段拟合(R0 的标签、R5 的 θ)与对照披露,绝不进特征,绝不进验证段宣判指标。
   验证段不披露 near 占比(只在训练段行披露)。

## 1. 研究问题

用事件日收盘时刻(含)之前可知的信息,能否选出"H60(60 交易日)持有能赚钱"的信号子集?
目标标签(仅训练用):near(锚点贴该股 ±60 交易日窗口阶段底 ≤10 个交易日)vs 其他(far / no_gt / 其他未入组)。

## 2. 宇宙(deployment universe)

每变体(v1/v2)分别构造:

- 基准集:事件日在该股引擎序列(load_market_data 返回,含前向缓冲,起点约 2025-11-03)上存在,且事件日下标 i_ev < len(该股引擎序列) − 60。
  参照数:v1 = 2449(自检 3 对齐,容差 ±2,差异逐笔解释)。
- 剔除并逐笔披露:(a) 事件日前全历史序列不足 120 个交易日(预期很少,次新股);(b) anchor_date 不在全历史序列(预期 0)。
- 宇宙 = 基准集 − (a) − (b)。

时间切分:训练段 event_date < 2026-04-01;验证段 event_date ≥ 2026-04-01。
**一切拟合(R0 的标准化参数与模型参数、R5 的 θ)只用训练段;宣判只在验证段。**

## 3. 特征(冻结清单,出数后不得增删)

全部只用 ≤ 事件日的数据,在全历史序列上按下标窗口,j = 事件日在全历史序列的下标,close_ev = close[j]:

- f1 回撤深度: close[j] / max(close[j−119 .. j]) − 1(≤0,越深越惨)
- f2 距60日低: close[j] / min(close[j−59 .. j]) − 1(≥0,越小越贴低)
- f3 距120日低: close[j] / min(close[j−119 .. j]) − 1
- f4 信号后已弹: close[j] / close[j_anchor] − 1(j_anchor = anchor_date 在全历史序列下标)
- f5 金叉水位: cross_dif(事件表列)
- f6 金叉抬升: dif_lift(事件表列)

f1~f4 用全历史日线 close(不复权,与引擎日线同源同口径)。
代码上特征函数只接收截断到事件日(含)的数组,从结构上杜绝前视。

## 4. 候选名单(6 个 + 1 基线,逐字冻结)

每个候选对宇宙每个事件输出接受/拒绝。

- **R0 六特征逻辑回归**: sklearn LogisticRegression(max_iter=2000),特征标准化(训练段均值/方差),训练段拟合(标签 near=1,其他=0),P≥0.5 接受。不调参。
- **R1 阶梯下跌排除**(用户假说1): 检查点 ck ∈ {j−100, j−80, j−60, j−40, j−20, j},m_k = min(close[ck−19 .. ck]);n_lower = #{k ∈ 1..5 : m_{k+1} < m_k}(六个 m 相邻比较 5 次)。n_lower ≥ 4 → 拒绝,否则接受。
- **R2 箱体收窄下破排除**(用户假说2): r_recent = (max(high[j−19..j]) − min(low[j−19..j])) / close[j];r_prior = 同式取 [j−79 .. j−60](含端点 20 根)。收窄 = r_recent < 0.6 × r_prior;下破 = close[j] == min(close[j−59 .. j])。两者同真 → 拒绝,否则接受。
- **R3 利空冲击排除(价格代理,见披露 1)**: 过去 60 个交易日(j−59 .. j)内,存在任一 收盘 ≤ 当日跌停价 + 1e-9(跌停收盘;跌停价取 stock_data/stk_limit 逐日文件,缺文件日视为无约束)或任一 open[k] / close[k−1] − 1 ≤ −5%(k 的前一根为全历史序列前一行)→ 拒绝,否则接受。
- **R4 全组合**: R0 接受 且 R1、R2、R3 均不拒绝。
- **R5 纯回撤深度**: f1 ≤ θ 接受;θ = 训练段 near 标签事件的 f1 中位数(只用训练段拟合)。
  θ 回填处(仅训练段,出数后不得改):**θ = −0.192115(v1)/ −0.203676(v2),2026-09-04 跑数后回填,仅训练段 near 事件 f1 中位数**。
- **ALL(基线,不是候选)**: 宇宙全部事件不筛选。

## 5. 交易模拟(与已复核 stage_ceiling 同款口径,逐条复刻)

事件日下一交易日(日历)开盘买;无报价 / 开盘 ≥ 涨停 − 1e-9 弃权(dropped_no_quote / dropped_limitup,计数不递补)。
10 万本金:px = open × 1.001(se.SLIPPAGE),sh = int(100000/px/100)×100,不足一手取一手,while sh>0 且 sh×px + buy_cost > 100000 + 1e-6 减一手,减到 0 记 dropped_cash。
入场日记持有第 1 日,第 60 个交易日(日历口径,停牌日计入持有日但不评估)收盘卖;收盘 ≤ 跌停 + 1e-9 顺延至下一非跌停收盘日;数据耗尽记 incomplete(计数,不进收益统计)。
净收益 = (sh×(xs−px) − 买佣 − 卖佣 − 印花税) / (sh×px + 买佣),xs = 卖收盘 × 0.999;成本直接调 se.buy_cost / se.sell_costs。
模拟与选择解耦:对基准集每个事件模拟一次 H60(基准集 ⊇ 宇宙 ∪ 全部 near/far 事件,自检 2 对拍用),再按各候选选择集 join 出每格。

## 6. 格子(配置为行,全出数,28 行)

变体 {v1, v2} × 候选 {ALL, R0, R1, R2, R3, R4, R5} × 段 {train, validation} = 28 行。
每行:n_universe, n_selected, n_closed, n_dropped_limitup, n_dropped_no_quote, n_dropped_cash, n_incomplete, 净笔均, 净中位, 胜率, cluster_t(cluster = 入场日,Liang-Zeger:score = x − x̄ 按簇求和 S_c,var = [G/(G−1)]ΣS_c²/n²,G<2 记 NaN),near_share_selected(选中集 near 标签占比,仅训练段行披露,验证段行记 NaN)。

## 7. 判活线(预登记,不移动球门)

每候选只在验证段宣判。
**过线 = 在两个变体的验证段上同时满足以下四条(两变体都过才算过)**:

1. n_selected ≥ 30(功效下限,不足记"功效不足"不算过)
2. 净笔均 > 0
3. cluster_t ≥ 2
4. 净笔均 ≥ 同变体同段 ALL 行净笔均 + 10pp

任一候选过线 → "当天可识别,A 活",过线候选即为识别器定版候选。
全部不过 → "当天不可识别,A 封档"。
train 段数字只披露不作判据。
R0/R5 若训练段拟合出的东西在验证段崩了,原样披露,不回炉。

## 8. 自检(全过才可出报告)

1. 特征因果断言:随机抽 5 个宇宙事件(种子 20260904),用"只取 ≤ 事件日数据"的手工切片重算 f1~f4,与管道输出一致(容差 1e-12);代码上特征函数只接收截断到事件日的序列。
2. 模拟对拍:near/far 事件的 H60 模拟净收益与 stage_ceiling/trades_ceiling.parquet(W==60 & H==60)逐笔比对,最大绝对差 ≤ 1e-9,状态分布一致。
3. 计数对齐:v1 基准集应 = 2449(±2,差异逐笔解释);最终宇宙 = 基准集 − 逐笔列出的剔除;每行 n_selected ≤ n_universe;ALL 行 n_selected = n_universe。
4. 交易因果:全部成交 entry_date > event_date。
5. 随机 3 笔成交(种子 20260904)打印完整生命周期供人工抽查。
