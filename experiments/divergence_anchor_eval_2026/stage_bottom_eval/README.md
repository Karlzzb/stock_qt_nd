# 阶段底标注测量 —— 预登记（先于任何跑数）

日期：2026-09-04。
性质：预登记纯测量实验，不改任何信号定义，不做策略调优。

## 研究问题

背离v6 金叉对金叉信号的两个锚定变体（变体1 区间最低价锚定 5646 事件、变体2 右侧确认精确锚定 5194 事件），
此前以 ±20 交易日窗口局部底为裁判的评估已落盘于 `../eval_summary.json`。
本实验把裁判换成阶段底（±60 / ±120 交易日窗口），重打同一套分，回答：v6 锚点是否贴着阶段底。

## Ground truth 定义（沿用既有配方，只改窗口参数）

每股全历史收盘序列（数据源 `/home/karl/repos/personal/stock_qt_nd/stock_data/daily/*.parquet`，
schema 过滤与扫描器一致：需 `ts_code` 列且 ≥100 行）上，交易日 t 满足：

```
close[t] == min(close[t-W .. t+W])  且  close[t] < min(close[t-W .. t-1])
```

即 ±W 交易日窗口内收盘最低；并列取最早（严格低于前窗即排除后者）。
W ∈ {60, 120}，两个窗口分别建基准、分开出表。

## 截断规则

- t 之后须仍有 W 个交易日数据（右侧窗口完整），数据末尾 W 个交易日内无法确认的低点不计。
- t 须落在 2026-01-01 之后（含），2026-01-01 之前的低点不计。
- 事件可评分性：仅事件日 ≤ 该股数据末尾 − W 个交易日的事件参与距离评分（逐股位置判定，
  与 ground truth 右端截断同一根线）。
- 每个窗口报告：可评分事件数 / 总事件数 / 真阶段底总数，截断造成的样本损失显式披露。
- 当前日线数据末尾为 2026-08-31；±120 窗口的可评分事件日约止于 2026 年 3 月初，样本损失预期很大。

## 指标清单（对每个窗口 × 每个变体，与 ../eval_summary.json 同配方）

- dist_median、dist_mean：锚点到最近真阶段底的交易日距离（并列取日期更早者）。
- dist_leN_pct，N ∈ {3, 5, 10, 15, 20, 30}：距离 ≤N 的事件占比。
- capture_leN_pct，同 N 档：距某事件锚点 ≤N 个交易日的真阶段底占该窗口真阶段底总数的比例
  （分母含无事件股票上的阶段底，与既有配方一致）。
- premium_median_pct / premium_mean_pct：锚点收盘 / 最近真阶段底收盘 − 1（附属读数，同既有配方）。
- 随机基线：与变体可评分事件数相同的随机锚点。
  每股模拟：在该股有效区间 [2026-01-01, 末尾−W交易日) 内均匀随机取 m 个锚点（m=该股该窗口可评分事件数），
  重复 R=100 次取均值，固定种子 20260903（与既有 random_baseline.py 同配方同种子）。
  输出随机锚 dist_leN_pct（命中率）与随机 capture_leN_pct 两组。
- 2×2 交叉表：以"锚点距 ±20 局部底 ≤5 天"（沿用 eval_summary 口径与既有
  `../ground_truth_lows_2026.parquet`）×"锚点距 ±60 阶段底 ≤10 天"做计数表，
  回答"v6 逮住的局部底里多少是下跌中继、多少贴着阶段底"。
  仅对 ±60 窗口可评分且该股在两个基准中均有低点的事件入表；基准缺失的事件单独披露。
- 与 ±20 既有结果并排对照表：eval_summary.json 的 dist_leN_pct / capture_leN_pct 原样抄入对照列
  （公共 N 档 {3,5,10,15,20}）。

## 预登记解释判据（出数后照此宣判，不移动球门）

仅 ±60 窗口参与宣判：

- dist_le10_pct ≥ 随机基线 dist_le10_pct 的 2 倍 → 判"有阶段底标注能力"；
- 1.2 ~ 2 倍 → 判"弱"；
- ≤ 1.2 倍 → 判"无"（A 方向封档依据）。

±120 窗口因样本截断只作参考读数，不做判据。
