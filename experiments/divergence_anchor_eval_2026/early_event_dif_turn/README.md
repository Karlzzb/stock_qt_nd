# DIF 拐点提前事件（实验B）—— 背离家族内的更早触发器对照 —— 预登记

本文件为预登记：先于任何跑数落盘写成，逐条钉死口径。
任务性质：预登记一次性实验，全程禁网络；仓库内除本目录（experiments/divergence_anchor_eval_2026/early_event_dif_turn/）外一律只读；v3_pipeline/ 严格只读。
执行解释器：.venv/bin/python。

## 1. 背景与动机

既有金叉对金叉底背离信号（定义：相邻 DIF×DEA 金叉对 C(k−1)→C(k)，dif_lift = DIF[C(k)] − DIF[C(k−1)] ≥ 0.001，价格区间最低收盘价创新低，事件日 = 金叉日 C(k)）的锚点质量好，但事件日比锚点晚（中位约 8~9 个交易日），反弹肉（锚点后 +5 日约 +6.7%）在信号发出前已被吃完。
本实验检验一个背离家族内的更早触发器：以最近一个已发生的金叉为参照，不等下一个金叉，在 DIF 拐点初步确认时提前开火。

## 2. 定义级改动披露（必须阅读）

本实验不是对既有金叉对金叉定义的优化或参数调优，而是一个新触发器定义。
既有定义的事件日原样前移是不可能的（见第 3 节），因此本实验的合法形态只能是"换一个更早就绪的触发条件"。
本实验的全部结果仅供用户决策是否修改既有信号定义，不构成采纳定义的充分条件；即便过判活线，也只是单段 2026 沙盒证据。

## 3. 为什么事件日不能原样前移（因果性论证）

既有定义的两个核心量在 C(k) 之前不可知晓：
- dif_lift 需要 C(k) 当天的 DIF 值，而金叉日本身只有到 C(k) 收盘才能确认；
- 价格区间最低收盘价需要看满到 C(k)，区间右端在 C(k) 之前未知。
因此直接把金叉对金叉的事件日前移是偷看未来，本实验不做任何形式的原样前移。

## 4. 新触发器定义（算法钉死）

记号：对每只股票，金叉日 t 满足 DIF[t−1] ≤ DEA[t−1] 且 DIF[t] > DEA[t]（两者均非 NaN），金叉序列按交易日行号排列。
对每个金叉 C_prev（作为潜在金叉对的左端），要求存在再前一个金叉 C_prev2（不足两个金叉的股票段跳过）。
监控区间：C_prev 之后到下一个金叉 C_next 之前的交易日，即 t ∈ (C_prev, C_next)；若 C_next 不存在（数据末段尾区间），监控到数据末尾。
在区间内逐日监控以下三个条件：
- 条件一（价格新低）：区间 (C_prev, t] 的最低收盘价 严格小于 区间 (C_prev2, C_prev] 的最低收盘价（左开右闭按行号，与既有变体 1 同口径）；
- 条件二（DIF 拐点没新低）：区间 (C_prev, t] 内 DIF 最低点位置 τ（并列取最早，即运行最小值严格变小时才更新）满足 DIF[τ] ≥ DIF[C_prev] + 0.001；
- 条件三（拐点确认）：DIF 自 τ 起连升 j 个交易日（严格递增），j ∈ {1, 2, 3}，即 t = τ + j 且 DIF[τ+1] > DIF[τ]，……，DIF[τ+j] > DIF[τ+j−1]。
三个条件都满足的首日 t = τ + j 即开火，该日称为开火基日。
每个金叉间区间对每个 j 配置最多开火一次；开火后该区间不再重复开火，等下一个金叉重置监控。
注意条件二具有单调失败性：运行最小值一旦跌破 DIF[C_prev] + 0.001 便永久失败，该区间此后不可能再开火。
失败单纪律：开火后最终没等到后续金叉（尾区间内数据结束）的事件必须计入统计，报告"后续金叉完成率"（类比预判挂买实验的确认率）。

### 4.1 风味 B1（对应既有变体 1 风味）

锚点 = 区间 (C_prev, 开火基日] 内最低收盘价所在交易日（并列取最早）。
事件日 = 开火基日 τ + j，无右侧确认等待。

### 4.2 风味 B2（对应既有变体 2 风味）

锚点搜索窗口 = (C_prev, 开火基日]（左开右闭按行号，不向开火基日右侧延伸）。
候选局部低点确认规则与既有变体 2 完全一致：左 3 右 2（收盘价 ≤ 左侧 3 日最低、严格小于右侧 2 日最低），候选按时间贪心做最小间隔过滤（相邻保留低点间隔 ≥ 3 个交易日，保留先出现者），右侧确认所需数据允许延伸到开火基日之后（见第 5 节因果性论证）。
锚点 = 窗口内收盘价最低的确认局部低点（并列取最早）；无确认局部低点则回退为窗口内最低收盘价所在日（并列取最早）。
事件日 = max(开火基日 τ + j, 锚点确认日 = 锚点日 + 2 个交易日)，与既有变体 2 的 max(C(k), anchor+2) 结构一致，对回退锚点同样适用。
若事件日超出数据末尾则丢弃该事件（与既有变体 2 的 anchor+2 出窗丢弃一致），丢弃数量单独披露、不计入完成率分母。

## 5. 因果性论证（事件日所用全部数据 ≤ 事件日）

- 条件一：运行最低收盘价只用 (C_prev, t] 内数据，t ≤ 事件日。
- 条件二、条件三：DIF 运行最小值与连升判定只用 (C_prev, t] 内数据，t = τ + j ≤ 事件日。
- B1 锚点：区间右端 = 开火基日 = 事件日，所用数据 ≤ 事件日。
- B2 锚点：候选低点的左侧 3 日数据 ≤ 开火基日；右侧 2 日确认数据最晚到 锚点日 + 2 ≤ 事件日。
- B2 锚点选择的细微因果性：窗口尾部的候选低点（开火基日 −1、开火基日当天）的确认数据最晚到开火基日 + 2，看似可能超过事件日。
  但贪心过滤按时间升序处理，尾部候选是否被保留不影响任何更早候选的保留状态；尾部候选只有在自身收盘价低于全部更早保留低点时才会成为锚点，此时锚点确认日 = 锚点日 + 2 > 开火基日，事件日随之后移到锚点确认日，所用确认数据仍 ≤ 事件日。
  因此锚点选择结果所依赖的全部数据 ≤ 事件日，无偷看未来。
- 事件日落在 2026 样本窗口内的过滤是事后样本筛选，不改变事件日的可知性。

## 6. 口径

- 行情：stock_data/daily/*.parquet 未复权日线；schema 过滤：需同时含 ts_code 与 vol 列，行数 ≥ 100，与 scan_v1.py / scan_v2.py 完全一致。
- MACD：本实验不直接信任 talib.MACD 输出做扫描，而是用与 predictive_entry 实验同一内部种子口径自行复算 DIF/DEA：快慢 EMA 同在第 25 行播种（快 EMA12 种子 = SMA(close[14:26])，慢 EMA26 种子 = SMA(close[0:26])），DEA 在第 33 行以 DIF_int[25:34] 的 SMA 播种，DIF 对外输出自行号 33 起。
  复算实现直接 import 复用 predictive_entry/predictive_scan.py 的 macd_internal 函数，不复制实现。
  金叉检测、dif_lift、条件二/三全部使用复算值；talib.MACD 输出仅用于自检对拍。
- 样本窗口：事件日 ∈ [2026-01-01, 2026-08-31]，与 events_v1/events_v2 完全一致；参照金叉可在窗口之前（与既有两变体一致）。
- 前瞻收益：收盘对收盘、不含成本，close[t+N]/close[t] − 1，N ∈ {5, 10, 20, 30, 60} 个交易日；数据末端不足 N 日的事件该档剔除（与 forward_returns.py 同口径）。
- 聚类稳健 t 值：对 +10/+20 日前瞻收益按 event_date 聚类，单样本均值检验，方差估计 Var = (G/(G−1)) × Σ_g s_g² / n²，其中 s_g 为聚类 g 内去均值残差之和，G 为聚类数，n 为样本数；t = 均值 / 标准误。

## 7. 自检闸门（不过则停，原样报告）

闸门一（复算对拍）：确定性抽样 20 只股票（排序文件列表等距取样），复算 DIF/DEA 与 talib.MACD 直接输出的最大绝对偏差必须 ≤ 1e-9；同时全市场任何一只股票偏差 > 1e-9 即硬失败停机。
闸门二（零容差复现）：用同一套复算管线完整复现既有金叉对金叉事件（金叉检测 + dif_lift ≥ 0.001 + 变体 1 价格条件 + 事件日窗口过滤），得到的 (ts_code, cross_date) 集合必须与 events_v1.parquet 完全一致，缺失数与多余数均须为 0。
任一闸门不过 = 管线 bug，停止并原样报告，不出任何事件表与收益表。

## 8. 网格与指标

网格：2 风味（B1/B2）× 3 个确认天数 j ∈ {1, 2, 3} = 6 行，一次性出数，不做任何事后追加。
每行指标：事件数、覆盖股票数、后续金叉完成率、升级为既有变体 1 事件率（补充列：后续金叉完成且 dif_lift ≥ 0.001 的比例；价格条件由条件一单调性自动继承）、事件日距锚点交易日的距离中位/均值、+5/+10/+20/+30/+60 日前瞻收益的均值/中位/胜率（%）、+10/+20 日按 event_date 聚类的 cluster-robust t。
基线行一并出：
- 全市场 2026 无条件前瞻收益：引用 forward_returns.json 的 baseline 块（口径与本实验一致，注明出处）；
- 既有变体 1 / 变体 2 事件日前瞻收益：引用 forward_returns.json 的 v1.event / v2.event 块（注明出处），其事件日距锚点距离由本脚本按事件表与行情重算。

## 9. 判活线（铁律）

某一行"有戏" ⟺ 同时满足：
1. +10 日前瞻收益均值 > 0；
2. +10 日聚类稳健 t ≥ 2；
3. +10 日均值比同风味既有事件日的 +10 日均值高 ≥ +2 个百分点（B1 对照 v1.event 的 −0.7123%，阈值为 ≥ 1.2877%；B2 对照 v2.event 的 −0.3540%，阈值为 ≥ 1.6460%）；
4. 后续金叉完成率 ≥ 70%。
六行全部不过线 = 判死，原样报告，阴性结果合法。
即便过线也必须注明：单段 2026 沙盒结果，不构成采纳定义的充分条件。
严禁加码：网格、条件、阈值、窗口、指标全部冻结；跑数后不做任何参数再调、不做子样本挑选、不追加新配置；发现 bug 则修复后全量重跑并在最终报告披露。

### 事件表列词典（中文全称）

- ts_code：股票代码
- event_date：事件日（开火日；B2 含锚点确认等待）
- anchor_date：锚点日
- anchor_close：锚点收盘价
- anchor_kind：锚点类型（区间最低收盘价 / 确认局部低点 / 回退区间最低收盘价）
- cross_prev_date：左端金叉日（C_prev）
- cross_prev_dif：左端金叉日 DIF 值
- cross_prev2_date：再前一个金叉日（C_prev2）
- tau_date：DIF 拐点日（τ，区间内 DIF 最低点，并列取最早）
- tau_dif：拐点日 DIF 值
- dif_floor：DIF 没新低门槛值（DIF[C_prev] + 0.001）
- fire_base_date：开火基日（τ + j）
- j：拐点确认连升天数
- dist_event_anchor_trade_days：事件日距锚点的交易日数
- completed：后续金叉是否完成（区间是否存在下一个金叉）
- next_cross_date：后续金叉日（未完成则为空）
- lead_days_vs_next_cross：相对既有金叉日信号的提前交易日数（next_cross − event，未完成则为空）
- dif_lift_next：后续金叉对的 dif_lift = DIF[C_next] − DIF[C_prev]（未完成则为空）
- became_v1_event：是否升级为既有变体 1 事件（完成且 dif_lift_next ≥ 0.001）
- fwd_ret_5 / fwd_ret_10 / fwd_ret_20 / fwd_ret_30 / fwd_ret_60：事件日收盘起 +N 交易日收盘对收盘前瞻收益（不足 N 日为空）
