## 一、裁决口径(用户拍板,冻结)

1. **窗口**:事件日 ∈ 2011-09-01 ~ 2026-08-31,逐字沿用 #32 §一.1(含截断条款与已披露代价)。
2. **判活线 = 口径 D(纯现金字面版)**:同时满足以下三条——
   - 单位在投超额 = excess_cash ÷ capital_utilization > +10pp;
   - 资金利用率 capital_utilization ≥ 0.5;
   - sharpe_cash > 0.5(纯现金口径权益曲线,日收益均值/标准差×√252,口径同 #32 §五)。
   - excess_cash = 纯现金口径净年化超额 = 策略年化 − 基准年化,基准 = 上证指数,口径逐字沿用 #32。
3. **宣判规则**:每格独立对判活线、全出数;多格过线时按单位在投超额(纯现金)取首;无终审段(沿用 #32 披露 3)。
4. **多重比较披露**:格子总数 = 12,180(§三),全部出数全部对线。

## 二、动机与机制说明(出数前披露)

- 张力已闭合(#39):五种仓位规则、22,220 格证「资金利用率 ≥0.5 且单位在投超额 >10pp」联立不可达;三条条件中唯一绑死的是资金利用率 0.5(#39 头部格在投超额 +13.54pp 与 sharpe_cash 0.819 双过、卡利用率 0.324)。
- 本实验的机制回答:持有期是资金利用率定义(日均在持市值 ÷ 总资金)里尚未动过的乘性因子——H 拉长直接延长每笔在持天数,不减入场笔数、不改单仓金额、不改接入集合的挑选逻辑;#32 已证 H25 全程优于 H10/H20,阶段底语义(前后约 60~120 交易日尺度上成立的中期低点)也指向中线持有。
- **诚实预期管理(先于跑数落盘)**:
  ① 在投质量未知——短线(10~25 日)+9~13.5pp 的单位在投超额在 60/120 日尺度是否保持,无先验保证;25 日以后的持仓收益曲线本战役从未测量。
  ② 屏障族钝感预警——E1/E2 共 29/35 出场含止盈止损屏障,多数仓位可能在 H 到期前触屏障出场,H 拉长对这两族作用有限;机制作用预期集中在 E0/E3/E4/E6/E7 等以时间为止或让利润奔跑的族。
  ③ 现金耗尽形态——利用率抬升伴随现金耗尽日增多,dropped_cash 与 dropped_slot_full 上升会改变实际接入集合,在投质量随接入集合而变,两条件仍可能此消彼长。
  ④ 尾部截断加重——H=120 时约 2026-03 起的事件持仓被数据耗尽截断,截断笔数占比高于既往实验,逐格计数披露。
- **判死条款**:若本实验仍 0 格过主线,则「口径 D 下该信号族不可交易」的终审链闭合:事件层有价值(#31)、短线组合层 12,240 格全死(#32)、五种仓位机制 22,220 格证利用率与在投质量联立不可达(#37~#39)、持有期维度 12,180 格再证——战役判死,建议封档。
