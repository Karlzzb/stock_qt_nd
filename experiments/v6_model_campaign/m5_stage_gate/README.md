3. **组合骨架(终审同型,#46 第 5 条)**:P7 精选加厚仓位 + E1_A6 出场 + H=60(标签赛当选标签 = 次日开盘入场净收益幅度回归标签,60 个交易日视野,adjudication_v6.json winner=net_ret_60d)。

4. **网格(18 格,每格独立对线全出数)**:爆发日挑选规则 6 条 = {M 模型分数排序} ∪ {S1 先到先得 / S2 前20日跌幅最深 / S3 种子强度 / S4 随机 / S5 已弹最少+量比最冷} × 槽位数 K ∈ {3,5,10}(#46 第 3 条钉死三档;P7K3 为名义骨架锚,K 三档为其网格扩展)。

   - **M 模型分数排序(本阶段新增,口径钉死)**:信号日候选按 score 降序;平局按 ts_code 升序(事件键 (ts_code, event_date) 全池唯一,平局裁决确定性完备);取前 n_free 名;score NaN 排最后(val 段实测零 NaN,防御保留)。

5. **每格指标(配置为行全出数)**:成交笔数 n_trades、净笔均(全部成交笔 net_ret 算术均值)、cluster_t(按入场日聚类的 Liang-Zeger 稳健 t,#31 §2.4 口径,底座 `cluster_t` 函数原样)、胜率(净收益>0 笔数占比,覆盖率→门槛方向表述)、资金利用率(日均在持市值 ÷ 100 万);信息性披露列 = 净年化超额(纯现金 excess_cash,基准上证指数)、sharpe_cash、年化(纯现金)、基准年化、接入/丢弃分类计数。
6. **主门(生死,#41 第二轮裁决第 4 条原文)**:任一 K 档,M 模型排序格净笔均 ≥ max(S1~S5 同 K 档净笔均) + 2pp 且该格 cluster_t ≥ 2 → 过门进 M6;18 格全不过(三个 K 档主门全不过)→ 模型路线判死,如实落盘回用户拍板。
   - 差值 = M 格净笔均 − 同 K 档 S1~S5 净笔均最大值,单位 pp,阈值 ≥ +2pp(≥ 含等号,与裁决原文「不低于……加两个百分点」一致)。
   - cluster_t 阈值为该 M 格自身的 cluster_t ≥ 2。
7. **副门(信息性不判死)**:precision@top10% 相对池基线提升落盘。
   - **口径钉死(全段 pooled)**:排序全集 = val 段有效标签(status_60d=='closed')事件 24,247 起;按模型分数降序(平局 ts_code 升序)取前 ⌈10%⌉ = 2,425 名,其标签 H=60 净收益>0 占比 = precision@top10%。
   - 池基线 = 同一全集(24,247 起)的净收益>0 占比(实测 0.459768,出数时以重算为准)。
   - 提升 = precision@top10% − 池基线,pp 落盘。
   - 标签无效事件 158 起(dropped_limitup 107 + truncated_exhausted 47 + dropped_cash 4,占 val 事件 0.65%)不参与副门——其净收益无定义,计入会混淆可成交性与信号质量;本条即该口径的预登记披露。
8. **本阶段不出任何测试段数字**;模型分数表 test 行只作零开仓断言的对象。

## 二、日历延伸决断(规格未钉死处,先于跑数落盘 disclose)

- 事件窗口 = 2020-01-01 ~ 2023-12-31(seg=='val' 子集);**回测日历终点 = 2023-12-31 后第 90 个上证指数交易日 = 2024-05-21**(H=60 视野约 60 个市场日 + 30 个交易日顺延缓冲)。
- 理由:M3 标签构建(labels_v6.parquet)对 2023 年末事件同样延伸出场至持仓按机制平仓(标签截断只发生在个股数据耗尽);阶段门要与标签口径同机制对账(§四.2),出场侧必须允许持仓走完机制;入场/排序决策只用 ≤ 信号日信息 + M4 一次性产出的分数,入场侧零泄漏。
- 代价披露:① 约 2023 年 11 月入场持仓的出场用了 2024-01 ~ 2024-05 行情(与标签口径一致,如实披露);② 资金利用率/sharpe_cash/净年化超额按延伸日历全程计算,尾部约 90 个日历交易日为纯出场延伸段(信息性披露列,不入主门);③ 个股数据先于日历终点耗尽的持仓按末日已知价估值留仓至日历终点(truncated_exhausted,逐格计数披露,与 #40 窗口终点条款同型)。
- **硬断言**:全部 18 格 truncated_window == 0(不允许出现「日历终点到了而个股数据未尽却仍未能按机制平仓」的持仓);若违例,日历终点顺延至 +120 个交易日重跑并在此落修订记录。

## 四、自检(施工必带,不过则失败;另落 selfcheck_m5.py 独立证伪式复核)

1. **引擎口径回归(与 #40 机制一致性对账)**:取 #40 冻结产物 runs/ALL__H60__S{1..5}__P7K3__E1_A6/trades.parquet 五格,抽事件 ∈ seg=='val' 的已成交单;与本阶段同配置格(S1~S5,K=3)的成交单按 (ts_code, event_date) 求交集,逐笔对账**市场机制字段**(entry_date/entry_raw/entry_price/exit_date/exit_reason/exit_raw_price/exit_exec_price/held_rows/deferred_days)浮点差 0。
   - 窗口不同 ⇒ 组合状态(现金/空槽)不同 ⇒ 接入集合与股数不同,属预期;故只比交集、只比市场机制字段(入场行/入场价/出场触发/出场价由行情与 E1_A6 参数决定,不依赖组合状态;entry_price = entry_raw×1.001 亦与股数无关),不比 shares/net_pnl;交集规模与两侧独有笔数逐格披露。
2. **成交单对账(引擎口径 vs 标签口径同机制,容差 1e-9)**:每格成交单对 labels_v6.parquet 逐笔对账——
   - 入场侧(全部成交笔):entry_date 与标签 entry_date 逐位一致(标签入场侧 H 不变性已由 M3 断言);
   - 同机制子集(逐笔判定):成交笔满足 exit_reason=='horizon' 且 held_rows==60 且 deferred_days==0(个股无行情间隙零、顺延零 ⇒ 引擎出场日 = 入场后第 60 个个股行情行 = 标签机制)且引擎 shares == 标签制股数(按标签口径 BUDGET=10 万对该笔 entry_price 独立重算)者,断言 |引擎 net_ret − 标签 net_ret_60d| ≤ 1e-9(同式同输入,预期逐位相等),且 exit_date 与标签 exit_date_60d 逐位一致;
   - 子集规模逐格披露;tp/sl 出场笔与股数因组合状态不同(K<10 或现金约束)的笔不入子集(机制/本金口径不同,非对账对象,披露)。
3. **模型分数接入断言**:scores 与事件键一对一(§三.2 合并断言);val 行 score 非 NaN 全覆盖(24,405/24,405);**标签 NaN 事件不得成交**——逐格断言:成交笔的事件在标签表 status_60d ∈ {closed} ∪ {dropped_cash 且 10 万本金买不起一手(按该笔 entry_price 独立重算:100 股成本 > 10 万 + 1e-6)};dropped_cash 例外笔(本金口径差:标签 10 万 vs P7K3/K5 名义 33.3/20 万,val 段仅 4 起候选)逐格计数披露,其余标签无效状态(dropped_limitup/truncated_exhausted/dropped_no_quote/truncated_no_next)零成交硬断言;embargo/test/pre2001/train 行零开仓(全部成交笔事件键 ∈ seg=='val' 键集)硬断言。
4. **确定性**:S4 格(K 三档)双跑逐位一致(summary+stats 除 runtime_sec + trades + equity);全 18 格双跑逐位一致(同口径,落 detcmp_m5.log)。
5. **底座完整性**:run_long_hold.py md5 校验 == a8f1cca6d2bad167899454f896f6d026;引擎内置断言(资金守恒逐日流水回放零容差、入场日>事件日、双口径对账 ≤0.05 元)逐格生效,任一失败即中断。
6. **selfcheck_m5.py(独立证伪式复核)**:不 import M5 驱动任何函数,自写代码从落盘产物(runs/*.parquet、summary_stage_gate_m5.csv)独立重算:18 格全部指标(净笔均/胜率/cluster_t 自写实现/资金利用率自 equity_curve 重算/信息性列)与 summary 对拍(浮点容差 0,自写重算要求逐位一致);主门宣判独立重算;副门 precision@top10% 从 scores+labels 独立重算;§四.1/§四.2/§四.3 对账从 parquet 独立重跑;另以全新子进程重跑 2 格(M×K3 与 S4×K3)与落盘 trades 逐位对拍;结果落 selfcheck_results.json,all_pass=true 才算完。
