## 一、裁决口径（用户拍板，冻结）

1. **窗口**：事件日 ∈ 2011-09-01 ~ 2026-08-31，逐字沿用 #32 §一.1（含截断条款与已披露代价）。
2. **判活线 = 口径 D（纯现金字面版）**：同时满足以下三条——
   - 单位在投超额 = excess_cash ÷ capital_utilization > +10pp；
   - 资金利用率 capital_utilization ≥ 0.5；
   - sharpe_cash > 0.5（纯现金口径权益曲线，日收益均值/标准差×√252，口径同 #32 §五）。
   - excess_cash = 纯现金口径净年化超额 = 策略年化 − 基准年化，基准 = 上证指数，口径逐字沿用 #32。
3. **宣判规则**：每格独立对判活线、全出数；多格过线时按单位在投超额取首；无终审段（沿用 #32 披露 3）。
4. **多重比较披露**：格子总数 = 1,890（§三），全部出数全部对线。

## 二、动机与机制说明（出数前披露）

- #37 头部格 v6-3__H25__S0__P5__E1_A6：单位在投超额（纯现金）+9.27pp（离 10pp 线差 0.73pp，三条条件中最接近的一项）、sharpe_cash 0.643 已过线、**资金利用率 0.281 < 0.5 成为卡线项**。
- P5"全接+摊薄"在稀疏强池上接入数上升（338 vs P1 的 247~249），但单仓摊薄使日均在持市值不升反降；绑线从"在投质量"翻转为"资金利用率"。
- 本实验的机制回答：把单仓名义金额整体加厚（K 分母从 10 降到 3/5/7），直接抬高日均在持市值。
- **近似尺度不变性预警（诚实预期管理）**：单位在投超额 = 超额 ÷ 利用率，对纯加厚近似不变；0.73pp 缺口只能靠两条次生通道闭合——① 最低佣金 5 元门槛的成本拖拽减轻（P5 摊薄产生大量 2 万元以下小仓，佣金占比超过万 2.5 名义率）；② 现金耗尽形态改变。若 per_cash 不动，加厚只抬利用率与超额总量，判活仍可能 0 格——此预期先于跑数落盘。

## 三、网格与 P6 规则（冻结）

1. **P6 加厚弹性仓位规则（本实验唯一新增机制）**：
   - 信号日收盘决策：当日池内信号**全部接入**，无仓位数上限；网格不含 sel 维，内部遍历固定用 ts_code 升序（确定性），逐字沿用 #37 P5 的接入语义。
   - 单仓名义金额 = 100 万 ÷ max(K, 当日池内信号数 S)，**K ∈ {3, 5, 7} 为网格维**。K=10 即退回 P5 名义；S > K 时全部接入、单仓摊薄（与 P5 同形态）。
   - 现金再摊薄：单仓金额 = min(名义金额, 信号日收盘后可用现金 ÷ S)，因果与顺序无关性论证逐字沿用 #37 §三.1。
   - 入场执行时现金不足 1 整手 → 丢弃记 dropped_cash，不递补（沿用 #32/#37）。
   - 入场日开盘的二次仓位检查对 P6 恒放开，dropped_slot_full 恒 0。
2. **网格**：池(6: v6-1~v6-5 + ALL) × H(3: 10/20/25) × 出场(35，清单逐字沿用 #32 §3.1) × K(3: 3/5/7) = **1,890 格**。pos 段取值 P6K3 / P6K5 / P6K7，sel 段固定 S0。
3. **不变部分**：信号池、入场口径、成本常量、出场族执行语义、双口径记账、统计指标口径全部逐字继承 #32 §二/§三/§五，不重扫、不调参。
4. **对照**：P5 同 (池, H, 出场) 配置的数字取自 #37 冻结产物 summary_elastic.csv；P1/P2 取自 #32 冻结产物 summary_portfolio.csv；均不重跑。

## 七、披露（预写，出数后原样保留）

1. 种子源自 2026 沙盒探索性扫描（沿用 #31 披露 1）。
2. 窗口砍掉 2008 产粮年，样本内大股灾 regime 只剩 2015（沿用 #32 §一.1）。
3. 无终审段：全窗口一次出数，如实披露（沿用 #32 §七.3）。
4. P6 加厚显著提高单票集中度（K=3 时单仓名义 33.3 万 = 总资金三分之一），组合波动与回撤结构异于 P1~P5；口径 D 的 sharpe_cash 条件即对此的风险约束，不另设集中度上限。
5. 口径 D 为拍板的判活线，旧终审线（+15pp 且 Sharpe>0.5，判活口径记账）只作参考列出数；本实验不回溯改判 #32/#37 已归档结论。
6. 单位在投超额对纯加厚近似尺度不变（§二预警），本实验的判活希望寄于成本拖拽减轻与现金耗尽形态改变两条次生通道；若 0 格过线，该近似不变性即为结构性解释而非实现缺陷。
7. 稀疏性是定义级约束（#35 已论证）：加厚只能重排既有的在持市值，不能创造信号；利用率条件能否过线同样受此上限约束。
