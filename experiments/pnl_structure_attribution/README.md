## 三、第一问指标定义（事件级单笔盈亏结构，逐格）

收益一律用净收益（扣完成本，#31 §2.3 口径）：笔均/中位用 `net_ret`，金额用 `net_pnl`（每笔独立约 10 万本金，元）。

1. 基本结构：n（closed 笔数）、净笔均、净中位、胜率（`net_ret>0` 笔数占比）、亏损笔数占比（`net_ret<0`）、持平笔数（`net_ret==0`，披露）、盈利笔均、亏损笔均、盈利笔中位、亏损笔中位、|亏损笔均| ÷ 盈利笔均。
2. 金额份额：毛利润 GP = Σ net_pnl（盈利笔）；毛亏损 GL = Σ net_pnl（亏损笔，负数）；总净盈亏 NP = GP + GL；亏损金额占毛利润比 = |GL|/GP；占净盈亏比 = |GL|/|NP|。
3. 尾部集中度：按 `net_ret` 升序稳定排序（tie-break：ts_code、event_date），最差 5%/10% 笔（k = max(1, floor(n×X%))）吞掉利润占比 = |Σ 最差 k 笔 net_pnl|/GP；最好 5%/10% 笔贡献占比 = Σ 最好 k 笔 net_pnl/GP。
4. 左尾拖累：剔除最差 X% 笔（X ∈ {1, 5, 10}）后净笔均，与原始净笔均并列。
5. 极值：最好/最差单笔净收益。

## 四、第二问指标定义（事件级 → 组合层落差分解，头部格）

锚点（全部重算，并与 #35/#32 已复核数字逐位对账，见 §六自检）：

- 池均值 m_pool = v6-1/H25/窗口/closed 的 `net_ret` 均值（= +4.17%，n=3,293）。
- 成交笔事件级均值 m_acc：头部格 trades 按 (ts_code, event_date) 回连 trades_seed 同过滤子集，内连接 861 笔的 `net_ret` 均值（= +2.54%）。
- 被拒信号均值 m_rej：池内未被回连命中的 2,432 个信号的 `net_ret` 均值（= +4.75%）。
- 组合实收笔均 m_real：头部格 trades 自身 `net_ret` 均值（= +2.31%，n=866，E2_B8 实际出场）。
- excess_cash = +4.9391pp、excess_idx = +7.4116pp、资金利用率 u = 0.614456（头部格 stats，#32 已复核）。

分解梯（加法链，单位 = 年化超额 pp；在投超额定义 = 纯现金口径超额 ÷ u，沿用 #35 错配 1 的线性分解）：

1. 锚点 I_pool = I_real ÷ (r_sel × r_exit)，其中 I_real = excess_cash ÷ u，r_sel = m_acc ÷ m_pool（仓位竞争质量比），r_exit = m_real ÷ m_acc（出场族保留比）。
   含义：若仓位竞争不稀释信号质量且出场不截断，单位在投本金的年化超额。
2. 项 a 仓位竞争质量差 = I_pool × (r_sel − 1)。
3. 项 d1 出场族截断（含 5 笔未匹配残差）= I_pool × r_sel × (r_exit − 1)。
4. 项 c 资金闲置摊薄 = I_real × (u − 1)。
5. 项 b 空仓口径 = excess_idx − excess_cash（判活口径 − 纯现金口径，#35 错配 2 已算出 +2.47pp）。
6. 闭合恒等式：I_pool + a + d1 + c + b = excess_idx（残差 < 1e-9，自检）。
7. 项 d2 单笔盈亏结构本身：不是传导损失项——它决定锚点 m_pool 本身的高低。用第一问的剔除最差 X% 结果量化：若池内无最差 5% 笔，m_pool 从 +4.17% 抬到多少，锚点 I_pool 同比放大到多少（标注为情景说明，不进加法链）。

辅助表：池 / 成交 / 被拒 / 实收四个子集的结构对照（n、净笔均、胜率、盈利笔均、亏损笔均、|GL|/GP、最差 10% 吞掉占比、最好 10% 贡献占比），回答"仓位竞争是否改变了盈亏结构"。
