## 一、口径与记号（钉死，与 #31 §2.1 逐字一致）

- 价格序列：个股**不复权**日线全历史，按行号索引；`DIF, DEA, _ = talib.MACD(close)`（12/26/9 默认参数，全历史一次性计算）。
- 金叉日 t：`DIF[t-1] <= DEA[t-1]` 且 `DIF[t] > DEA[t]`（均非 NaN）。
- 金叉三元组：相邻三次金叉，行号记 `i2 = C(k-2)`、`i1 = C(k-1)`、`j = C(k)`（事件日行号）。
- 事件条件：`dif_lift = DIF[j] - DIF[i1] >= 0.001`，且区间 `(i2, i1]` 最低收盘价严格大于区间 `(i1, j]` 最低收盘价（区间按行号左开右闭）。
- 事件字段：`event_date = 第 j 行交易日`；锚点行 `a = (i1, j]` 内最低收盘价所在行（并列取最早）；`anchor_close = close[a]`。
- 种子特征：`dd20 = close[j] / max(close[max(0, j-20) .. j]) - 1`（含事件日共 21 根，j<20 截断到 0）；`bounce = close[j] / anchor_close - 1`。
- 种子阈值（#31 §2.2）：v6-1 `dd20<=-0.15 且 0.02<bounce<=0.08`；v6-2 `dd20<=-0.20` 同 bounce 带；v6-3 `dd20<=-0.25` 同 bounce 带；v6-4 `dd20<=-0.15`；v6-5 `dd20<=-0.25`。
- 急跌窗口：下文 `W = 行号区间 [max(0, j-20), j]`（与 dd20 同窗口，含事件日共至多 21 根）；`t0 = max(0, j-20)` 为窗口首行。

## 二、因果性主引理（全清单共用的验收基石）

引理 1（行号上界蕴含因果）：本清单每条特征的全部输入均为个股序列行号 `<= j` 的行（close/open/high/low/vol/amount）与由这些行派生的 DIF/DEA 值，故最晚可知时点 = 事件日（第 j 行）收盘。

引理 2（MACD 递推无前视）：talib.MACD 为 EMA 递推，`DIF[t]`、`DEA[t]` 只是 `close[0..t]` 的函数；全历史一次性计算不改变第 t 行取值的因果性（warm-up 段 NaN 已自然剔除）。
注：EMA 初始化使「截断到第 t 行重算」与「全历史重算」在第 t 行存在指数衰减的微小差异，验收断言 3 以烧入期 + 容差方式处理。

引理 3（锚点不晚于事件日）：`a in (i1, j]` 左开右闭，故 `a <= j`，`anchor_close` 在事件日收盘含之前可知（#31 §2.2 已注明「因果干净」）。

边界情形（各特征公式已含守卫）：
- `a = j` 允许（事件日收盘价即区间最低），此时 `bounce = 0`、`j - a = 0`，凡除以 `j - a` 的特征用 `max(1, j - a)` 守卫。
- `j < 20`（上市初期）时 `W` 截断到行号 0，窗口长度 `|W| = j + 1 < 21`，占比极小（#31 已披露）；凡除以窗口长度的特征用实际长度。
- 个股行数 < 100 已跳过（扫描器口径），事件级特征不再重复该过滤。

## 七、因果性验收断言清单（机器可检查草案，供战役规格引用）

以下断言针对「特征构建产物表」（键：`ts_code, event_date`），在特征构建阶段完成后逐条执行；全部通过才准进标签赛。

- 断言 1（行号上界）：对每一事件、每一特征，构建日志记录其引用的个股序列最大行号 `max_row_used`，断言 `max_row_used <= j`（事件日行号）恒成立。
- 断言 2（区间语义自洽）：从特征层重算 `i2, i1, j, a, min_prev, min_cur`，断言与事件表一致：`event_date == 第 j 行交易日`、`anchor_date == 第 a 行交易日`、`anchor_close == close[a]`、`a in (i1, j]`、并列取最早规则复现一致。
- 断言 3（MACD 无前视）：抽样至少 100 事件，对每个事件用截断序列 `close[0..j]` 重算 talib.MACD，断言 `|DIF_trunc[j] - DIF_full[j]| < 1e-8` 且 `|DEA_trunc[j] - DEA_full[j]| < 1e-8`（仅对 `j >= 100` 的事件执行，绕开 EMA 烧入差异；差异超容差即视为前视实现 bug，停线排查）。
- 断言 4（dd20 窗口与符号）：断言 `dd20 <= 1e-12` 恒成立（close[j] <= max(close[W])）；断言窗口长度 `|W| == min(21, j + 1)`。
- 断言 5（锚点因果与取值域）：断言 `a <= j`、`anchor_close > 0`；断言 `a == j` 蕴含 `bounce == 0`（±1e-12）。
- 断言 6（事件条件自洽）：断言全体事件满足 `dif_lift >= 0.001` 且 `min_prev > min_cur`（从原始日线重算，与事件表逐行核对）。
- 断言 7（量纲缩放不变性）：对标注「无量纲」的特征，抽样事件将 `close/open/high/low` 同乘 lambda = 2.718 重算（DIF/DEA 随 close 同步缩放），断言特征值变化 `< 1e-9`；量纲为交易日/计数/布尔的特征断言严格不变。
- 断言 8（环境特征来源）：标注「快照覆盖」的特征（E2/E3/E4 及 v5 三来源重建特征）断言取自日频特征快照第 `event_date` 行，快照本身已通过其既有因果验收；特征构建器不得直接读事件日后行。
- 断言 9（特征-标签隔离）：特征表列名不得含 `label_` 前缀；标签表（次日开盘 → 第 H 日收盘净收益）由独立构建器产出，join 键仅限 `(ts_code, event_date)`；断言两表构建器无共享中间产物。
- 断言 10（成员资格重算一致）：F6~F10 从 B0/C0 重算，断言与 #31 §2.2 阈值逐字一致，且嵌套链 `v6-3 ⊂ v6-2 ⊂ v6-1 ⊂ v6-4`、`v6-5 ⊂ v6-4` 零违反（#31 已验证口径的继承检查）。
- 断言 11（缺失披露）：凡含守卫 NaN 分支的特征（B3/B4/B6/C4/E1），断言 NaN 占比落盘披露，且 NaN 不得用事件日后信息填充。
