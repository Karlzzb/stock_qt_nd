## 二、v5 十九候选标签机器盘点

### 2.1 候选清单（十九个，固定顺序：狙击标签在前，其后 cur 族九视野、open_exec 族九视野）

生成口径总则（`label_race.compute_return_labels`，构建驱动 `build_race_labels.py`）。
收益标签按股票在 `stock_data/daily` 全序列上因果计算（行 t 的标签只用行 > t 的数据，由 label_candidates 的 shift 构造保证），再按 (ts_code, date) 合并到各池事件。
收益为 NaN（尾部截断/停牌顺延产出 NaN）时标签保持 NaN，不由 (ret > 0) 吞成 0；NaN 保留，剔除时机在跑训驱动按段登记（只对 train/val 登记计数，test 零逐行统计）。
构建过真实数据因果性断言：抽样 20 只（实测 19 只）截掉序列头部 200 行重算，交集日期标签逐位一致；键缺失 0 事件。
全部十九候选均为毛收益口径：不含滑点、佣金、印花税，不含整手折算，不含开盘涨停买不进剔除。

| # | 工程名 | 中文全称 | 精确定义 | 生成口径 |
|---|---|---|---|---|
| 1 | hit_N20_k2.0 | 背离狙击命中标签（T+1 开盘入场，20 交易日内触及 +2 倍 ATR(14)） | 1{ max(high[T+1 .. T+20]) ≥ open[T+1] + 2×ATR(14)[T] } | 各池 labels.parquet div 组逐位对齐装载（`load_div_labels`），源头 `divergence_lab.py`：窗口 high[T+1..T+N]、ATR(14) 取信号日 T；条件 sig+N ≤ n−1 且 open[T+1]>0 且 ATR 有限，否则 NaN |
| 2~10 | cur_pos_{h}d，h ∈ {3,5,10,15,20,25,30,45,60} | T 收盘入场收益大于零二分类标签（h 个交易日视野） | 1{ close[T+1+h]/close[T] − 1 > 0 } | `label_candidates.cur_return(d,h)` = close.shift(−(h+1))/close − 1；持有 h+1 个交易日（T 收盘买入） |
| 11~19 | open_exec_pos_{h}d，h ∈ {3,5,10,15,20,25,30,45,60} | T+1 开盘入场收益大于零二分类标签（h 个交易日视野） | 1{ close[T+1+h]/open[T+1] − 1 > 0 } | `label_candidates.open_exec_return(d,h)` = close.shift(−(h+1))/open.shift(−1) − 1；自 T+1 开盘持有 h 个交易日收盘，与 cur 族出场日对齐 |

视野语义登记（v5 t6_report 原文）：两族出场统一为 T+1+h 收盘，cur 族持有 h+1 日、open_exec 族持有 h 日，出场日对齐保证比较公平。
另有 `label_candidates.max_forward_return`（mfr 族，T+1 开盘入场、窗口内最高价可达收益）在库但不在十九候选内，v5 未参赛。

### 2.2 v5 裁决规则（#20 预登记 + #26 置顶评论执行细则，全部先于结果落盘）

- 双池结构与兜底：主池（m_fractal15_full）训练段事件数实测 2838 < 3000，#20 预登记兜底触发——主备合并池（行并集不去重、event_id 加池前缀、pool 溯源列）升为正赛（train 22963 ≥ 3000），主池降为对照；裁决只在正赛。
- 网格：num_leaves{15,31,63} × min_data_in_leaf{50,100,200} × learning_rate{0.05,0.10} × feature_fraction{0.6,0.8} = 36 组全因子（≤50 上限），其余参数沿用 #25 冒烟口径。
- 每配置管线：训练段五折时间序列折外概率（按事件日分块、折界不落日内）→ 逻辑回归校准层（输入 [p, p²]）→ 全训练段终模（轮数 = 五折 best_iteration 均值取整）→ 指标表行 = train_oof（折外口径）与 val（终模+校准口径），指标表以配置为行。
- 裁决指标（`train_eval_pipeline.topk_precision / evaluate_segment`）：头部五名精确率 = 按事件日截面取概率 top-min(5, 当日事件数)，日加权（主口径）与事件加权（辅口径）双出；平均精确率 = sklearn average_precision_score。
- 每候选选配置：val 头部五名精确率（日加权）最高 → 平局 val 平均精确率较高 → 再平局网格序靠前（`select_best_config`）。
- 总裁决（`adjudicate`）：十九候选各取当选配置后，val 头部五名精确率（日加权）最高者当选；平局取 val 平均精确率较高者，再平局取候选序靠前者；且当选候选的 val 平均精确率不得低于十九候选 val 平均精确率的中位数，不满足则本赛季无当选（阴性结论落盘，不降格另选）。
- 复现性与纪律：十九候选当选配置 OOF 全程复跑逐位一致断言（不可旁路）；test 段零触碰（只在场断言）；断点续跑与心跳日志；独立证伪式复核五项全 PASS 后锁定。
- v5 结果（仅作口径示例，不作 v6 任何输入）：正赛当选 hit_N20_k2.0，val 头部五名精确率（日加权）0.5750214224507284、val 平均精确率 0.622474953133874 ≥ 中位数 0.5794460048968032；对照（主池）同标签当选（0.5164556962025316 / 0.6282588395379161 ≥ 0.5599044253188422），方向跨池一致。
- 「两池双胜」表述溯源：#20/#26 的正式规则文本为「合并池正赛裁决 + 主池对照复跑确认跨池稳健」；#30 User Story 18 将其概括为「两池双胜」并宣告该规则在单池口径下不再适用。

## 三、v6 适配提案

### 3.1 已裁决的硬约束（本提案不得逾越）

- 池：ALL 全池 96,577 事件训练，单池、无主备结构（#41 第二轮裁决 Q1）。
- 只建模变体1，变体2 出 scope（第二轮裁决 Q5①）。
- 标签 = 次日开盘价入场 → 第 H 个交易日收盘出场，净收益扣成本常量（滑点双边 0.1% + 佣金万2.5 最低5元按10万本金折算 + 印花税分时段）（第二轮裁决 Q5②，机制细则向 #31 §2.3 看齐）。
- 开盘涨停买不进、退市/数据耗尽截断 → 标签剔除 + 占比披露（第二轮裁决 Q5③）。
- 二分类（净收益>0）+ 幅度回归双头都进标签赛，主用哪个由实证裁决（第二轮裁决 Q5④）。
- H ∈ {10,20,25,60} 全赛，头部裁决（第一轮裁决 6）。
- 切分原样采用 #30：训练 2001-01~2019-12 / 验证 2020-01~2023-12 / 测试 2024-01~2026-08，段界两侧各 30 交易日清洗式隔离带（第二轮裁决 Q3）。
- 阶段门：验证段、终审同型组合骨架上模型排序爆发日 top-K 净笔均 ≥ 最好手工挑选规则 +2pp 且 cluster_t ≥ 2（第二轮裁决 Q4）。

### 3.2 v6 候选清单提案（八个候选：四档 H × 双头）

统一标签口径（每个候选共用，逐条对齐 #31 §2.3 与第二轮裁决 Q5）。
信号日 T（背离金叉事件日，变体1）的下一交易日开盘入场：买入执行价 px = open×1.001（0.1% 买入滑点）。
开盘无报价 → dropped_no_quote 剔除；开盘价 ≥ 当日涨停价 − 1e-9 → dropped_limitup 剔除（买不进，不递补）。
每笔独立 10 万本金整手折算：sh = int(100000/px/100)×100，不足一手取一手，while sh>0 且 sh×px+买佣 > 100000+1e-6 减一手，减到 0 → dropped_cash 剔除。
入场日记持有第 1 日；第 H 个交易日（按个股序列行号计）收盘出场：卖出执行价 xs = close×0.999（0.1% 卖出滑点）。
出场日收盘 ≤ 当日跌停价 + 1e-9 → 顺延至下一非跌停收盘日；数据耗尽（含退市）→ truncated_exhausted 剔除。
净收益 = (sh×(xs−px) − 买佣 − 卖佣 − 印花税) / (sh×px + 买佣)。
成本常量复用冻结引擎 `strategy_engine.py`（只读）：佣金双边万2.5、单笔最低5元；印花税 0.1%（2023-08-27 含之前）/ 0.05%（2023-08-28 起）；整手 100 股；滑点单边 0.1%；价格比较容差 1e-9。
涨跌停判定用 `stock_data/stk_limit/YYYYMMDD.parquet`（2007-01-04 起），缺文件日视为无涨跌停约束（2007 年前受影响成交占比须披露；#31 以 v1/H20 格计为 11320/95386 = 11.9%，本赛按本池本 H 重算披露）。
剔除类别（dropped_no_quote / dropped_limitup / dropped_cash / truncated_exhausted / 键缺失）逐类计数按段落盘并披露占比（只对 train/val 出逐类计数与指标，test 段零触碰）。

### 3.3 裁决规则草案（单池口径，跑赛前预登记落盘后方可开跑）

1. 正赛池 = ALL 全池（变体1），无主备结构、无兜底升级条款；死锁条款：若训练段有效标签事件数 < 3000，本赛季不裁决、回用户拍板（v5 的 3000 阈值保留为纯样本量保险丝，不再触发任何池切换）。
2. 网格沿用 v5 预登记 36 组全因子（num_leaves × min_data_in_leaf × learning_rate × feature_fraction，≤50 上限）；二分类头 objective 沿用 v5 口径，回归头 objective 改 regression、评估指标改回归对应，其余参数与复现性四件套沿用 #25 口径。
3. 每配置管线沿用 v5：训练段五折时间序列折外（按事件日分块、折界不落日内）→ 全训练段终模（轮数 = 五折 best_iteration 均值）→ train_oof/val 双段指标表，配置为行。
   校准层分头处理：二分类头沿用逻辑回归校准层 [p, p²]；回归头不配概率校准层，排序直接用折外/终模预测原值（裁决只看排序型指标，单调变换不影响结果，此条须在预登记中写明）。
4. 主裁决指标（提案核心变更）：验证段头部五名净笔均（日加权）——每个事件日按模型分数排序取 top-min(5, 当日事件数)（无信号日不计），对所取事件按该候选自身 H 口径的真实净收益求日截面均值，再按日等权平均；同指标附带 cluster_t（按入场日聚类的 Liang-Zeger 稳健 t，#31 §2.4 口径）。
   二分类头分数 = 校准后概率，回归头分数 = 预测幅度原值，两者在同一净收益标尺上可比，双头同场裁决成立。
   换主指标的理由：v5 主指标（头部五名精确率）对回归头无定义，无法支撑第二轮裁决 Q5④ 的双头同赛；头部五名净笔均与阶段门主指标（爆发日 top-K 净笔均）同型同单位，标签选择直接服务阶段门目标，且与口径D 终审的超额 pp 单位一致。
   辅助指标（落盘、不作裁决输入）：二分类头另出 v5 口径的头部五名精确率（日加权/事件加权）与平均精确率（仅供与 v5 历史产物口径对照参考；v5 实证结论不作任何输入）；回归头另出 top-5 命中率（所取事件净收益>0 占比）。
5. 每候选选配置：主指标最高 → 平局 cluster_t 较高 → 再平局网格序靠前。
6. 总裁决：八候选各取当选配置，主指标最高者当选；平局 cluster_t 较高 → 再平局候选序（§3.2 表序）靠前。
7. 双约束（保留 v5 的防硬选机制并加显著性闸）：当选候选主指标 ≥ 八候选（各取当选配置）主指标的中位数；且当选候选 val cluster_t ≥ 2。任一不满足 → 本赛季无当选，阴性结论如实落盘，不降格另选。
8. 复现与纪律沿用 v5 全套：八候选当选配置折外全程复跑逐位一致断言（不可旁路）；test 段零触碰只在场断言；段界与隔离带硬断言；泄漏列排除断言；断点续跑与心跳日志；独立证伪式复核通过后锁定，锁定后候选集与当选结果不再变更。
9. 与阶段门的衔接：标签赛当选只决定训练目标（H 与主头），不构成过门证据；模型是否过阶段门由第二轮裁决 Q4 主门在策略层实证（终审同型组合骨架上 top-K 净笔均 ≥ 最好手工挑选规则 +2pp 且 cluster_t ≥ 2），标签赛主指标是该主门的事件级同型预览。
10. 双头主用裁决：八候选同场赛跑即天然完成主头裁决——当选候选属哪个头，定版模型主用哪个头；副头概率/幅度可保留为参考输出，是否作为辅助特征或辅助排序入后续阶段，由特征精选与策略层阶段另行裁决，不在本赛预登记范围内。
    天然归属：v5 的 cur / open_exec 收益族与 v6 的 net_pos 族为天然二分类；狙击标签 hit_N20_k2.0 为天然二分类（触及式）；v6 的 net_ret 族为天然回归；不存在两头皆可的候选。
